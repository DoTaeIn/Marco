# Bash 기초 실습

`bash_local_report.sh`는 허가된 로컬 디렉터리를 변경하지 않고 관찰해 Markdown 보고서를 만드는 연습 프로그램이다.

```bash
bash practice/bash_local_report.sh --dir . --keyword "[논증]" --output /tmp/nai-report.md
```

이 스크립트에서 확인할 그래프 노드는 다음과 같다.

- `위치매개변수`: `--dir`, `--keyword`, `--output` 파싱
- `인용`: 모든 경로와 입력값을 큰따옴표로 전달
- `조건문`·`함수`: 입력 검증과 오류 처리
- `파이프라인`·`리다이렉션`: 파일 목록과 보고서 생성
- `반환상태`·`정리처리`: 오류 메시지, 임시 파일, `trap`
- `대상제한`·`검증전실행`: 로컬 디렉터리만 받고 `/`는 거절

대상 디렉터리는 본인이 소유하거나 명시적으로 허가받은 로컬·교육용 범위로 한정한다. 스크립트는 대상의 파일을 수정하지 않지만, 지정한 `--output` 경로에는 보고서를 쓴다.
