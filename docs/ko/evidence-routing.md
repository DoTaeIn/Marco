# 근거가 그래프를 고른다

2026-09-12. 라우터 순위 하나로 그래프를 정하던 것을, 상위 후보의 **근거까지
열어 보고** 정하게 바꿨다. 바꿔 말하기 **31.8% -> 40.2%**, 밖 거절은 24/24
그대로다. 새 지식도 새 모델도 안 들였다.

## 왜 여기였나

오늘 잰 실패 지형이 이렇다.

```
정답 그래프가 라우터 1등        31.8%
정답 그래프가 상위 셋 안         51.8%   <- 20%가 놀고 있다
그래프 안에서 개념 짚기(대조)     99.8%   <- 이 층은 거의 완벽하다
```

**라우터는 표면을 보고 판정은 근거를 본다.** 근거 쪽이 훨씬 센 신호인데, 그
신호를 라우팅 결정에 안 쓰고 있었다.

틀린 것들을 보면 한 모양이다.

```
장기 기후가 바뀌는 것
  이긴 것  정보보안_기초  0.435  "데이터가 몰래 바뀌지 않는 것"
  정답     기후학_기초    0.423  "기후가 뭐야"
```

표면으로는 0.012 차이라 뒤집히는데, **근거를 물어보면 기후학만 답할 수 있다.**

## 고친 것

`engine.answer` 는 이미 후보 여덟 개를 세션으로 열어 근거가 서는지 보고
있었다. 다만 **점수 순서로 처음 근거가 선 것**을 바로 썼다. 조금 뒤에 있는
후보가 더 확실히 답할 수 있어도 보지 못한다.

이제 상위 셋까지 열어 보고 **판정이 제일 센 것**을 쓴다.

```
겨루는 값 = (판정 차례, 라우터 점수)
판정 차례 = 인정 > 계산완료 > 상태판정 > 목표주장 > A > C > 근거없음 > 미지 > B2
선언에 없는 판정 = 0 (모르는 판정을 근거로 세지 않는다)
```

지켜야 할 선 둘을 시험으로 못 박았다.

- **근거가 안 선 후보는 순위가 높아도 답을 못 가져간다.** 라우팅을 뒤집는 게
  아니라, 근거를 댈 수 있는가로 다시 고르는 것이다.
- **라우팅 문턱 아래 후보는 아예 열지 않는다.** 열면 밖 물음이 어딘가에 걸린다.

## 잣대에 줄을 하나 더했다

기존 여덟 줄은 라우터만 잰다. 실제로 답할 때는 후보를 세션으로 열어 보는데,
재는 자리가 다르면 시스템이 하는 일을 못 본다. `안 물음 · 근거까지 봄` 을
더했고 기존 줄은 손대지 않았다.

| 줄 | 값 |
|---|---:|
| 대조(별칭 그대로) | 373/400 |
| 안 물음(뺀 별칭) | 127/400 · 31.8% |
| 안 물음 · 셋 안 | 207/400 |
| **안 물음 · 근거까지 봄** | **161/400 · 40.2%** |
| 밖 거절 | 24/24 |

**밖 거절이 안 깎이는 이유가 중요하다.** 밖 물음은 어느 그래프에도 진짜
근거가 없어서 셋 다 막힌다. 별칭을 늘릴 때와 정반대다 — 별칭은 받아들이는
폭을 넓혀 거절을 깎았는데(48개에 -2), 이것은 **폭을 안 넓히고 고르는 눈만
바꾼다.**

오늘 진단한 세 건이 실제로 바로잡혔다.

```
지진이 낸 에너지의 크기    기계_기초     -> 지진학_기초   인정
장기 기후가 바뀌는 것     정보보안_기초  -> 기후학_기초   인정
산과 평야 같은 땅의 모양   의류섬유_기초  -> 지리_기초     인정
오늘 서울 날씨 어때                    -> 못 답함       미지
```

## 처음 잰 값이 45.0% 였던 것

시제품에서는 45.0% 가 나왔는데, 그것은 **라우터가 이미 맞힌 것은 다시 판정에
안 넘겼다.** 전부 다시 판정하면 그중 일부가 뒤집힌다. 40.2% 가 정직한 값이다.

## 아직 아닌 것

정답 그래프가 **상위 셋 밖**인 것이 47.8% 로 남아 있다. 이 변경은 셋 안에
들어온 것만 건진다. 그 47.8% 는 라우터 자체를 바꿔야 하는 자리이고,
계층 라우팅·구조 동의어·무관층 경쟁이 노리는 곳이다.
