# 수량 자리의 한글 수사

숫자로 주석된 관계 슬롯은 `numeral_semantics.parse_numeral`로 값을 해석한다.
어휘는 `data/semantic/relations.json`의 `numerals`에 있고, 코드는 낱말과
값을 조합한다. 고유어의 십 단위와 일 단위, 한자어의 내림차순 십·백·천 단위를
처리한다. 숫자와 단위 사이의 공백도 허용한다.

예를 들어 '파란 구슬은 서른두 개 있다. 초록 구슬은 이백십칠 개 있다.
파란 구슬 다섯 개를 꺼냈다. 지금 파란 구슬은 몇 개야?'는 실제 엔진에서
검색 없이 27개로 계산된다. 숫자나 색상별 답은 실행 코드에 없다.

전체 원문을 치환하지 않으므로 대상 이름 '공'이 숫자 0으로 바뀌지 않는다.
원문 증거의 위치도 보존한다. '두세', '여러', 중복·역순 단위는 확정 수량으로
사용하지 않는다. 숫자 슬롯의 정규식도 어휘 문자로 제한하여 다단어 대상 이름이
숫자 자리로 잘못 흡수되는 회귀를 막았다.

제한: 만 이상의 한자어 단위, 소수·분수·음수의 한글 표현, 문맥상 수사 중의성은
아직 지원하지 않는다. 이 변경만으로 고정 진단의 '덜어낸 뒤 보탰어' 같은 새로운
사건 서술까지 해석되는 것은 아니다. 전체 자연어 추론 목표는 계속 진행 중이다.
