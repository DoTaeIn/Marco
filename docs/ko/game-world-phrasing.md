# 게임 세계로 잰 바꿔 말하기

2026-09-11. 닫힌 세계 하나를 손으로 지어, 플레이어 말투로 라우팅을 쟀다.
**이 갈래에서 NPC를 붙이기 전에 알아야 할 숫자다.**

## 왜 쟀나

얼린 잣대는 일반 지식 그래프 905개 위에서 바꿔 말하기 31%를 낸다. 그것만으로는
원인이 안 갈린다 — 그래프가 너무 많아 서로 겹쳐서인지, 바꿔 말하기 자체를 못
따라가서인지.

색인 크기만 줄여 보면 반은 갈린다.

| 세계 크기 | 맞는 그래프로 감 |
|---:|---:|
| 911개 | 31.0% |
| 200개 | 32.8% |
| 100개 | 41.1% |
| 50개 | 45.3% |
| 30개 | 54.7% |

줄이면 나아지지만 구해 주지는 않는다. 나머지 반을 가르려고 **게임용으로 새로
지은 세계**에서 다시 쟀다.

## 무엇을 지었나

`graphs/게임세계/` 에 23개 — 장소·인물(대장간, 약초상, 여관, 경비초소, 폐광,
늪지), 만들기(무기, 물약, 채광, 약초채집, 수리, 마법부여), 규칙(화폐, 길드,
현상금, 내구도, 무게, 밤과날씨), 몬스터(고블린, 늪거인, 늑대), 의뢰 둘.

`data/benchmarks/game_world_phrasing.json` 에 플레이어 물음 94개. **그래프의
별칭을 한 글자도 베끼지 않았다** — 기계로 확인한다. 전부 처음 보는 말이다.

```
포션 어디서 팔아?      걔네 왜 떼로 와       검이 왜 자꾸 상해
잠은 어디서 자         무리 흩어뜨리는 법     짐 얼마나 들 수 있어
```

## 결과

```
게임 세계 그래프 23개 · 플레이어 물음 94개
==============================================
맞는 그래프로 감       33/94   35.1%
상위 셋 안            72/94   76.6%
못 고르고 미지         46/94   48.9%
틀린 그래프로 감        15/94   16.0%
==============================================
문턱을 무시한 순위 1등   50/94   53.2%
```

**마지막 줄이 천장이다.** 정답이 셋 안에는 77% 들어오는데 1등은 53% 다 —
정보는 있고 가르지를 못한다. 문턱으로는 그 천장을 못 넘는다.

| 문턱 | 맞음 | 틀림 | 미지 |
|---:|---:|---:|---:|
| 0.50 | 27.7% | 5.3% | 67.0% |
| 0.43 (지금) | 35.1% | 16.0% | 48.9% |
| 0.30 | 47.9% | 38.3% | 14.0% |

틀림을 줄이면 답이 줄고, 답을 늘리면 틀림이 는다. 고를 만한 자리가 없다.

## 별칭을 고치면 반만 간다

초벌은 서술형 긴 별칭으로 적었다 — **14.9%**, 그중 79%가 문턱 아래였다.
긴 문장은 짧은 물음이 덮지 못한다. 플레이어 말투의 짧은 별칭을 더하니
**35.1%** 가 됐지만, 틀린 답이 6% 에서 16% 로 늘었다. `얼마`·`어디서` 같은
짧고 흔한 별칭이 자석이 됐다 — `잠은 어디서 자` 가 장비수리로 갔다. 엔진의
짧은-줄 방어가 있는 바로 그 이유다.

## 이 숫자를 어떻게 읽나

- **35.1% 는 초벌 authoring 의 바닥이지 authoring 의 한계가 아니다.** 그래프와
  물음을 한 사람이 썼고, 실제 세계라면 미지 로그를 보고 플레이어가 쓴 말을
  계속 더한다.
- **그런데 그게 바로 미루기다.** 짧은 별칭을 더해 15%를 35%로 만든 것이 곧
  "플레이어가 할 말을 미리 적어 두기" 다. 늘려서 메우면 NPC가 아니라 대응표가
  된다.
- **천장 53% 는 분야를 안 가린다.** 23개짜리 전용 세계에서 나온 값이므로,
  그래프 수를 줄이는 방법으로는 더 못 올린다.

## 이 갈래에서 다음에 할 일

1. **이 갈래를 main 으로 최신화한다.** 지금 112 커밋 뒤처져 있어 kgpack v3,
   기하평균 점수, 모아 둔 한글 문법, 그래프 기반 대화 이해가 없다.
   `bench/game_world_phrasing.py` 는 그 엔진을 전제로 한다.
   합칠 때 충돌이 일곱 군데 난다 — 이 갈래가 한국어 이름 시절 코드에 기능을
   더했고(`engine.py` +346줄, `겪음읽기` 등) main 이 그것을 영어로 바꿨다.
   기계로 못 풀고 손으로 옮겨야 한다.
2. **최신화한 뒤 이 잣대를 다시 돌린다.** 35.1% 가 얼마가 되는지가 NPC 를
   붙일지 말지를 정한다.
3. 여기 23개는 `npc.py` 의 `World` 와 `graphs/npc_*.kg` 에 이어 붙일 씨앗이다.
   대장간 그래프의 볼드와 `npc_대장장이.kg` 의 톰은 아직 따로 논다.
