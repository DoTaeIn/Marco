# 조각은 원문보다 낮게 친다

2026-09-11. 라우팅에서 문장 조각의 점수에 0.90 을 곱한다. 문턱은 안
건드렸다. `안 물음 · 셋 안` 200 -> 202, 나머지 일곱 줄은 그대로.

## 무엇이 문제였나

`split_fragments` 는 긴 발화를 절 단위로 쪼개 후보를 늘린다. 점수는
`max(조각들)` 로 고른다. 그래서 **조각 하나가 엉뚱한 그래프에 높게
붙으면 원문의 점수를 덮는다.**

조각 내기를 꺼서 값을 갈랐다.

| | 대조 | 안 물음 · 셋 안 |
|---|---:|---:|
| 조각 켬 | **375** | 200 |
| 조각 끔 | 374 | **203** |

조각은 대조를 1 올리고 바꿔 말하기를 3 내린다.

처음에는 짧은 색인 줄을 막는 `_short_line = 8` 이 조각 때문에 안 걸리는
줄 알았다. 아니었다 — 잣대의 길이를 조각 길이 대신 발화 전체 길이로
바꿔 재봤더니 **여덟 줄이 하나도 안 움직였다.** 그 방어는 이 건과
무관하다.

## 고친 것

원문은 사람이 실제로 한 말이고, 조각은 우리가 쪼개서 만든 가설이다.
둘을 같은 자격으로 겨루게 두지 않는다.

```python
chunks = [(..., 1.0 if position == 0 else _FRAGMENT_WEIGHT)
          for position, chunk in enumerate(split_fragments(question))]
score.append((max(weight * _sparse_score(...) for ..., weight in chunks), n))
```

| 무게 | 대조 | 안 물음 · 셋 안 | 밖 거절 |
|---:|---:|---:|---:|
| 1.00 | 375 | 200 | 24/24 |
| **0.90** | **375** | **202** | 24/24 |
| 0.80 | 374 | 204 | 24/24 |
| 조각 끔 | 374 | 203 | 24/24 |

나머지 다섯 줄은 어느 값에서도 안 움직인다.

0.90 은 **차례를 세운 값**이지 눈금에서 고른 값이 아니다. 1.00 은 차례가
없다는 뜻이고, 너무 낮으면 조각이 아무 일도 못 한다. 잣대로는 부작용이
없다는 것만 확인했다.

## 아직 아닌 것

**이 잣대는 조각의 값어치를 못 잰다.** 조각은 `증거를 보면 A입니다.
따라서 B이고, 그러므로 C입니다` 같은 긴 여러겹 발화를 위한 것인데,
고정 물음 400개는 전부 짧은 한 문장이다. 비용만 보이고 이득은 안 보인다.

그래서 0.80 이 `셋 안` 을 204 까지 올려도 그것을 고르지 않았다. 긴 여러겹
발화 잣대가 생기기 전에는 이 값을 더 깎을 근거가 없다. 그 잣대를 만드는
것이 다음 일이다.
