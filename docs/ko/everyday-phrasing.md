# 실사용 말투 — 대응표를 지우고 계산으로 바꾼 자리

2026-09-11. 입력 이해가 적힌 글자와 똑같아야 걸리던 것을, 지식 그래프와
활용으로 바꿨다. 사람이 실제로 치는 말 74개에서 **12개에서 74개**가 됐다.
얼린 잣대는 안 나빠졌다.

## 무엇이 문제였나

`대화이해.phrases` 는 네 줄짜리 대응표였고, 글자가 똑같아야 걸렸다
(`language_components.py` 의 `item["text"] != text`).

```
안녕하세요        알아들음
안녕             못 알아들음
반갑습니다         못 알아들음
좋은 아침이에요      못 알아들음
땡큐             못 알아들음
```

**그런데 저 넷이 전부 `graphs/graph_대화예절.kg` 에 이미 적혀 있었다.**

```
*인사말: "안녕하세요" | "안녕" | "반가워" | "안녕하십니까" | "반가워요"
       | "반갑습니다" | "좋은 아침이에요" | "하이" | "헬로"
```

같은 지식이 언어팩과 지식팩에 두 번 적혀 있었고, 언어팩 쪽이 더 적었다.
엔진에 물으면 여섯 개 모두 1.00 으로 이 그래프에 붙는다. 계산하는 길이
이미 있었고 이미 맞혔는데, 옆에 있는 표가 그 길을 안 쓰고 혼자 틀렸다.

요청 쪽도 같았다. `"{target} 요약해줘"` 라는 겉꼴 틀이라서 `요약해 주세요`
와 `요약해 줄래` 를 놓쳤다. 셋은 같은 어간에 다른 어미가 붙은 것이고,
어미를 계산하는 `활용` 이 같은 파일 안에 있었다.

## 두 가지로 바꿨다

### 대화 말은 그래프에 묻는다

`graph_dialogue.GraphDialogueBackend` 가 `대화이해.backend` 로 꽂힌다.
별칭도 답도 `.kg` 에 있으므로 **인사말 하나 늘리는 일이 그래프 한 줄**이다.

실제로 그렇게 고쳤다. 처음 쟀을 때 `ㅎㅇ` 와 `ㄱㅅ` 만 틀렸는데, 코드를
건드리지 않고 `*인사말` 과 `*감사말` 에 한 낱말씩 더해 74/74 가 됐다.

답도 `[개념]` 에서 온다. 굳은 답 세 줄 대신 그래프가 가진 여덟 갈래가
나온다 — `별말씀을요`, `괜찮아요, 다시 말해 주셔도 돼요`, `그러게요`.

### 요청 말끝은 활용으로 만든다

언어팩에는 **동작 어간만** 적는다.

```json
"request": {
  "light_verb": "하", "auxiliary": "주",
  "auxiliary_endings": ["informal", "polite", "request_polite",
                        "request_ask", "request_ask_polite",
                        "request_honorific_ask"],
  "bare_markers": ["좀", "부탁해", ...],
  "actions": [{"stem": "요약", "intent": "request.summary"}, ...]
}
```

꼬리는 세 자리(군말 · 본용언 · 보조용언)를 각각 비울 수 있게 곱해서
만든다. `주 + request_polite` 가 `주세요` 를, `주 + request_ask` 가
`줄래` 를 내놓는다 — 청유 어미 네 개는 기존 연산(`epenthetic`,
`coda_suffix`)만으로 선언했다.

**곱해져 있다는 것이 요점이다.** 어미를 하나 늘리면 모든 동작이 그 꼴을
함께 얻고, 동작을 하나 늘리면 모든 어미를 공짜로 얻는다. 시험이 이것을
고정한다 — `request_polite` 를 빼면 `요약`·`설명`·`비교` 가 **함께**
`해 주세요` 를 잃는다.

## 라우팅 동의를 요구한다

한 그래프에만 물으면 긴 문장 안에 묻힌 짧은 말이 걸린다. 고정 물음
800개를 통과시켰더니 **31개가 대화로 잘못 먹혔다**.

```
DNS는 사람이 읽는 이름을 네트워크 주소 정보와 연결해 준다   -> dialogue
트리는 사이클이 없고 모든 정점이 연결된 그래프이다        -> dialogue
```

그래서 라우터도 이 그래프를 골랐을 때만 대화로 본다. 라우터는 905개를
견주므로 그 견줌을 여기서 다시 하지 않는다.

| | 라우팅 동의 전 | 동의 후 |
|---|---:|---:|
| 고정 물음 800개 중 대화로 먹힌 것 | 31 (3.9%) | **4 (0.5%)** |
| 밖 물음 24개 중 | 0 | 0 |

남은 넷은 `미안`, `됐어`, `말을 잘못했네`, `나중에 봐` 로 **전부 진짜
대화말**이다. 넷 다 `graph_대화예절.kg` 의 사례에 있다.

라우터가 없으면 대화로 보지 않는다. 확인하지 못한 것을 인정하지 않는다.

## 셈과 꼴

`3줄` 의 3도 `세 줄` 의 세도 같은 셈이다. 수사는 언어팩의 `numerals` 로
읽는다 — 아라비아 숫자만 알아보면 사람이 쓰는 절반을 놓친다.

낱말 자리는 `hangul.word_spans` 가 가린다. `발표자료` 의 `표` 를 꼴말로
읽으면 안 되고 `3줄로` 의 `줄` 은 조사가 붙어도 세는말이다. 그 구분은
한글 문법 한 군데에만 있어야 하므로 여기서 다시 만들지 않았다.

그 과정에서 `hangul._particles` 의 구멍을 메웠다. 주석은 이미
`'에·까지·도·만'` 을 말하는데 목록에는 없어서, `다섯 개만` 의 `개` 가
낱말로 안 보였다. 꼴이 안 바뀌는 조사 열둘을 더했다(`_epenthetic` 에
없으므로 받침이 있어도 그대로 붙는다). 얼린 잣대는 안 움직였다.

꼴말은 도구격일 때만 꼴이다. `표로 비교해줘` 는 꼴이고 `이 표 설명해
주세요` 는 대상이다. 어느 꼴로 붙는지는 받침이 정하므로 `pick_particle`
에 묻는다.

## 지운 것

`대화이해` 에서 `phrases`(4줄)와 `templates`(6줄)를 지웠다. 같은 지식이
`.kg` 와 `활용` 에 있으므로 두 번 적지 않는다. `replies` 는 고를 지식이
아예 없을 때 쓰는 `fallback` 한 줄만 남겼다.

영어 언어팩은 그대로다. `backend` 를 선언하지 않으므로 기존
`TemplateBackend` 로 돈다 — 새 부품은 한국어 문법에 기대고 있다.
