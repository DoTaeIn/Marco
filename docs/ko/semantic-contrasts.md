## 구현

관계 사실에 `polarity`와 `modality`를 보존한다. 명시적으로 부정한 삼중항은
긍정 추론의 전제나 중간 결론으로 쓰지 않는다. 이를 통해 부정된 중간 사실에서
새 결론이 파생되는 것도 막는다. 관련 없는 정상 경로는 유지한다. 부정은 반대
방향의 비교를 증명하지 않는다. 이 정책은 모순된 긍정/부정의 동시 존재에서
해당 사실의 사용을 보류하는 방식이며, 모든 비단조 논리를 구현한 것은 아니다.

예정·조건부 사실은 현재 상태에 적용하지 않고 관찰 기록에 남긴다. 실제로
이동하지 않았다는 사건과 현재 그 장소에 없다는 상태는 별개의 관계로 표현한다.
한국어 표면 표현은 주석 데이터에 추가했으며, 실행 코드의 이름별 정답 분기는 없다.
교정 학습도 부정/양태 주석을 저장하고 새 개체에서 다시 사용할 수 있다.

이미 해석된 질문이 전제 부족·모순으로 미지가 되면 엔진은 그 결과를 유지한다.
이후 유사도 검색으로 다른 그래프의 답을 붙이지 않는다. 예정 이동의 실제 UI
경로는 웹 연구 없이 기존 위치를 답하는 회귀 검사를 포함한다.
