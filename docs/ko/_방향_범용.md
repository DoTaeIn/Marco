# 범용 — 문서에서 답하는 엔진

main 에서 뻗는다. 목적은 **아무 문서 폴더나 넣으면 그것에 대해 답하는 것**이다.

> 이 파일은 다음 사람(또는 다음 AI)이 같은 길을 또 파지 않게 하는 것이 값어치다.
> 확인한 사실과 실제로 잰 수치만 적는다. 계획이나 각오는 적지 않는다.

## 지금 어디까지

물음 647개 기준(2026-09-03):

    코퍼스 안 320/435 (73%) · 코퍼스 밖 거절 81%
    의도-정의 100% · 이유 100% · 조건 93% · 실측 90% · 절차 88%
    안-바꿔말 5.8% · 영어 8.3% · 긴 물음 36% · 오타 38.5% · 밖-비슷한말 52.8%

시작점은 8% 였다.

> 예전 판에 바꿔말 16% · 영어 33% 로 적혀 있었는데 같은 로그를 다시 세니
> 5.8% · 8.3% 다. 낡은 수치였다.

# 인공일반지능까지 부족한 것

무엇이 막고 있는지를 **원인의 종류**로 나눈다. 고치는 방법이 종류마다 다르기
때문이다. 각 줄의 숫자는 전부 실측이다.

## 1. 재료 — 그래프에 관계가 없다

가장 크고, 가장 단순하고, 지금 제일 잘 풀리고 있는 자리다.

    문서그래프 엣지 10,466개 중
      같은조문 6,295 (60.1%)  ← "한 대목에 같이 나왔다"
      설명함   4,137 (39.5%)  ← "이 대목에서 언급된다"
      진짜 관계     34 (0.3%)  ← 사람이 _관계.json 에 손으로 적은 것

99.7% 가 인접이지 주장이 아니다. 노드 360개에 관계 엣지 34개면 노드 열 개당
하나라 길이 안 난다. 그래서 답의 70% 가 원문 40자를 그대로 옮긴 것이고,
`styles/한국어.json` 의 관계말 24종은 답 387개에서 **한 번도** 안 쓰였다.

법지식 그래프도 같다. 엣지 371,367개가 전부 같은조문·설명함이고, 개념엣지
3,880개(상위 3,053 · 정의 827)는 `엣지` 에 안 들어가서 `_인접`·`잇는길` 이
아예 못 본다. **관계말 경로에 닿는 노드가 0 / 7,183 이었다.**

### 고치는 법 — 이미 절반 했다

| 한 것 | 결과 |
|---|---|
| 관계 어휘를 엔진 상수에서 그래프 머리말로 | `npc_대장장이.kg` 가 법정 어휘 0개로 돈다 |
| `[공리]` — 증거를 안 묻는 노드 | 상식이 근거없음만 내던 것이 풀렸다 |
| 정의문에서 유(類) 뽑기 | 노이즈 827개 → 진짜 29개 |
| 국어사전에서 대상 뽑기 | 명사 30,227개 중 대상 5,975개 |
| 도식을 조상에 적고 사슬로 전파 | 씨앗 28개가 동작 낱말 27% 를 덮는다 |

**남은 일**: `개념엣지` 를 `엣지` 에 얹는 배선(`build.py` 한 줄), 그리고
`설명()` 이 발췌를 무조건 먼저 내보내는 순서를 고치는 것. 둘 다 작은데
아직 `dotaein/범용` 에 안 들어왔다(게임 갈래에서 실험만 했다).

## 2. 바꿔말 — 표면이 다르면 못 알아듣는다

**5.8%.** 사람이 원문에 없는 말로 물으면 거의 다 놓친다.

원인이 구조적이다. 정답률이 **질문 낱말이 원문에 그대로 있는 비율의 함수**다:

    원문 낱말 100%      71/74   95.9%
    70~100%             74/95   77.9%
    40~70%             104/185  56.2%
    40% 미만            60/107   56.1%

포함도 인코더는 '질문 조각 중 몇 할이 노드 안에 있나' 를 세므로 표면이
다르면 구조적으로 못 이긴다. 그런데 **신경망도 29%** 라 인코더를 바꿔서
풀리는 문제가 아니다. 표현 587개를 사람이 넣어 4% → 6% 였으니 표현
채우기의 천장도 낮다.

### 고치는 법 — 재료 쪽에서 우회한다

인코더를 이기려 하지 말고 **노드가 부르는 법을 늘린다**. 사전에서 유의어를
가져오는 길이 열려 있다 — 한국어기초사전은 뜻풀이만이 아니라 관련어를 담고
있고, 유(類) 사슬 자체가 상위어 사전이다. `합주 → 연주 → 일` 을 알면
"합주 시간" 을 "연주" 노드로 보낼 수 있다.

다만 **깊이 2 를 넘기지 마라**(아래 5번).

## 3. 밖-비슷한말 — 아는 낱말로 딴 얘기를 물을 때

**52.8%.** 코퍼스 낱말을 쓰면서 다른 얘기인 물음이 제일 잘 샌다. 포함도가
1.000 을 준다.

실제로 겪은 누출:

    "이 회사 조직도가 어떻게 되나요"  ->  "혹시 이 회사 로직가 어떻게 되나요 말인가?"

`오타고침` 의 자모 거리가 코퍼스 **밖** 낱말을 억지로 안쪽으로 끌어당긴다.
오타 교정기가 밖-누출 장치로 겸업 중이다.

### 고치는 법 — 잣대를 둘로 가른다

지금은 점수 하나와 문턱 두 개(`A_MIN`/`OK_MIN`)로 **"이 그래프 얘기냐"** 와
**"어느 노드냐"** 를 같이 결정한다. 그래서 둘이 서로를 인질로 잡는다.

    문턱을 낮추면 -> 밖-비슷한말이 더 샌다
    문턱을 올리면 -> 바꿔말이 더 죽는다

소속 판정과 대상 선택을 **다른 잣대로** 분리해야 한다. `_모르는말` 을 좁히는
것보다 이게 근본이다.

## 4. 텍스트에 안 쓰인 것 — 지금 제일 단단한 벽

**원문은 무엇인지는 적지만 무엇이 아닌지는 안 적는다.**

    세차 -> 자동차       사전에서 뽑힌다 (재현율 30% · 정밀도 8할)
    합주는 나눠 못 한다   아무도 그렇게 안 적는다
    연주 시간은 인원과 무관   마찬가지

`60명이 60분에 연주하면 120명은?` 에 답하려면 "이 일은 동시에 하는 일이라
사람을 늘려도 시간이 안 준다" 를 알아야 하는데, 연주·수면·회의 어느 정의문도
그 말을 하지 않는다. 사람은 당연해서 안 쓰고 기계는 안 쓰인 걸 못 읽는다.

동시성 표지(`동시에`·`함께`·`같이`)로 위키 45,760개를 훑어 288개가 걸렸는데
표본이 거의 다 쓰레기였다(`사전에 도표와 함께`, `고구려·백제와 함께`).

### 고치는 법 — 도식을 사람이 소수 적고 사슬로 퍼뜨린다

이건 텍스트에서 못 얻는다. 대신 **도식은 몇 개 안 된다.**

    가분작업 / 동시작업     인원을 늘리면 시간이 주나
    소모 / 비소모          쓰면 없어지나
    순서 있음 / 없음        바꿔도 되나

열 개 남짓을 한 번 적으면 유 사슬을 타고 낱말 수천 개에 걸린다.
`조사짝` 을 한 번 적어 모든 문장에 쓰는 것과 같은 지위다. 이미 그렇게
하고 있다 — 씨앗 28개가 동작 낱말 27% 를 덮는다.

**이것이 이 프로젝트가 LLM 과 다른 지점이기도 하다.** LLM 은 안 쓰인 것을
통계로 얼버무리고, 여기서는 사람이 한 번 적고 그 근거가 파일에 남는다.

## 5. 사슬이 길어지면 뜻이 흘러간다

전파는 되는데 깊이가 문제다.

    깊이  1: 21%   2: 27%   3: 31%   6: 41%   12: 46%
    표본 12개 중 맞은 것 — 깊이 2 는 10개, 깊이 12 는 절반 아래

무엇이 깨지는지 보면 명확하다:

    힘 -> 작용 -> 줌 -> 손 -> 부분 -> 범위 -> 구역    (결사반대가 '장소' 가 됐다)
    종교 -> 체계 -> 전체 -> 대상 -> 상인 -> 사람      ('대상(對象)' 이 '대상(隊商)' 으로)

한 칸 건널 때마다 동음이의가 갈아탈 기회가 생기고 그게 누적된다.

### 고치는 법 — 깊이를 늘리지 말고 동음이의를 풀어라

커버리지를 얻겠다고 깊이를 늘리면 정밀도로 갚는다. 대신:

- **품사·의미 번호로 갈라라.** 사전에 `대상01(對象)` · `대상02(隊商)` 이
  따로 있다. 지금은 표제어만 쓰고 동음이의 번호를 버리고 있다.
- 한 칸 건널 때 **원래 낱말과 뜻이 이어지는지 확인**하는 검사를 붙여라.

# 안 되는 것으로 확인된 길

다시 파지 마라. 전부 실제로 재고 접었다.

- **부정어·복합어 규칙**(사람 파싱 흉내). 65 → 63, 65 → 64
- **엣지를 문 찾기에 넣기.** 원점수 68 → 70 인데 파이프라인 이득 0
- **ko-sroberta 를 동의어 선생으로.** 낱말 하나엔 벡터가 무너지고(고갈=네임
  1.000) 문장을 줘도 구절↔개념은 대조군과 안 갈린다
- **이 코퍼스에서 분포 학습.** 필요한 낱말쌍이 문단 536개에서 0~2회
- **한자 공유로 낱말 잇기.** `주차(駐車)` 와 `자동차(自動車)` 가 `車` 를
  공유하니 이어질 줄 알았는데 **정밀도 5~10%** 였다. 무작위 16개 중 봐줄
  만한 것이 1~2개다.

      범유행(汎流行) -> 行 -> 한국은행     行 이 '다니다' 와 '은행' 으로 갈린다
      면제배갑(綿製背甲) -> 甲 -> 한화갑    한국 인명의 끝 글자가 다 걸린다
      면회(面會) -> 會 -> 의회             면회의 대상이 의회일 리 없다

  게다가 정작 필요했던 `세차`·`독서` 는 위키에 한자 풀이가 **아예 없었다**.
- **백과사전으로 일상 낱말 배우기.** 위키에 `세차`·`독서` 는 문서가 없고
  `연주`·`합주` 는 동음이의 문서뿐이다. 백과사전은 고유명사와 전문용어를
  정의하지 일상 행위를 정의하지 않는다. **국어사전이 맞는 재료다.**
- **소속 판정을 표면 신호로 가르기.** `밖-비슷한말`(52.8%)을 `안-바꿔말`과
  가르려고 신호 셋을 쟀는데 전부 안 갈렸다. 문서그래프 647문 기준 중앙값:

      신호                  안-바꿔말   밖-비슷한말
      어휘 덮음               0.50       0.50
      낱말이 한 대목에 뭉침       0.40       0.33
      뒤쪽 두 낱말 덮음          0.50       0.50

  `밖-일상`(0.25)·`밖-딴분야`(0.25)는 어휘 덮음으로 잘 갈린다 — 그래서 그
  둘은 이미 92% 맞는다. **`밖-비슷한말`만 `안-바꿔말`과 구분이 안 된다.**

- **어휘를 빈도로 좁히기.** 어휘 3,272개 중 **68%가 코퍼스에 한 번 이하로**
  나온다(`설치`·`구현`·`자료구조`·`경고등` 은 발췌에 0번인데 어휘에 있다).
  그래서 `_모르는말` 이 어떤 질문에도 빈 목록을 낸다. 2회 이상만 안다고
  하면 신호가 살아나긴 한다(모르는 말 개수 밖 1.28 vs 안 0.78). 그러나
  전체로는 손해다:

      갈래           지금    2회이상
      밖-비슷한말     20/36   27/36   (+7)
      밖-딴분야       57/65   60/65   (+3)
      밖-일상         53/61   56/61   (+3)
      안-바꿔말       54/69   33/69   (-21)
      안-김          22/25   12/25   (-10)
      안-영어         11/24    2/24   (-9)
      합계          553/647 507/647  (-46)

  **밖-비슷한말과 안-바꿔말은 같은 축의 양 끝이다.** 어휘를 좁히면 '원문에
  없는 말' 이 늘고 그것이 곧 바꿔말의 정의다. 한 축을 조이면 반대쪽이
  정확히 그만큼 풀린다. 문턱을 어디에 두든 이득이 0에 가깝다
  (규칙 '모르는 말 N개 이상이면 밖': N=1 -37 · N=2 -3 · N=3 +1).

  필요한 것은 잣대를 하나 더 만드는 것이 아니라 **다른 종류의 신호**다 —
  '이 낱말을 아느냐' 가 아니라 '이 낱말이 무엇이냐'.

- **동시성을 표지로 뽑기.** `동시에`·`함께` 로 45,760개를 훑어 288개가
  걸렸는데 거의 다 쓰레기였다. 4번 참고.
- **유 사슬을 깊이 제한 없이 타기.** 5번 참고.

# 된 것

- **정의문에서 대상 뽑기**(`build.대상뽑기` · `목적그래프.py`). 목적이 수단을
  제약하는 관계를 원문에서 가져온다.

      "세차는 자동차를 씻는 일이다"  ->  ('자동차', '씻')  ->  .kg

      나: 걷는 게 더 빠르다     -> 그건 세차 를 할 수 있느냐와 상관이 없다
      나: 걸어서 간다          -> 자동차두고감 는 그렇다. 그런데 자동차있음 가 걸린다

  아무도 그 제약을 안 적었다. 위키 첫 문장에서 나왔고 `[공리]` 노드에
  `@출처` 가 붙는다.

- **국어사전 추출**(`사전뽑기.py`). 명사 30,227개에서 유 28,308 · 동작 9,643 ·
