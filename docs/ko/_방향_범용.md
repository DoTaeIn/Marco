# 범용 — 문서에서 답하는 엔진

main 에서 뻗는다. 목적은 **아무 문서 폴더나 넣으면 그것에 대해 답하는 것**이다.

## 지금 어디까지 (2026-09-03, 물음 647개 기준)

    코퍼스 안 320/435 (73%) · 코퍼스 밖 거절 81%
    의도-정의 100% · 이유 100% · 조건 93% · 실측 90% · 절차 88%
    안-바꿔말 16% · 영어 33% · 오타 35% · 밖-비슷한말 53%

시작점은 8% 였다.

## 이 갈래가 이겨야 하는 것

- **바꿔말 16%.** 사람이 원문에 없는 말로 물을 때. 신경망도 29% 라 둘 다
  못 하는 문제다. 표현 587개를 넣어 4% -> 6% 였으니 표현 채우기의 천장은 낮다.
- **밖-비슷한말 53%.** 코퍼스 낱말을 쓰면서 딴 얘기인 물음. 포함도가 1.000 을
  준다. 여기가 제일 잘 샌다.
- **인용밖에 못 한다.** 답 647개 중 원문 인용 54% · 틀 조립 37%. 관계말 24종이
  준비돼 있는데 실제로 쓰인 것은 2번이다.

## 안 되는 것으로 확인된 길

- 부정어·복합어 규칙 (사람 파싱 흉내). 65 -> 63, 65 -> 64
- 엣지를 문 찾기에 넣기. 원점수 68 -> 70 인데 파이프라인 이득 0
- ko-sroberta 를 동의어 선생으로. 낱말 하나엔 벡터가 무너지고(고갈=네임 1.000)
  문장을 줘도 구절↔개념은 대조군과 안 갈린다
- 이 코퍼스에서 분포 학습. 필요한 낱말쌍이 문단 536개에서 0~2회
- **한자 공유로 낱말 잇기.** `주차(駐車)` 와 `자동차(自動車)` 가 `車` 를 공유하니
  한글 표면이 안 겹쳐도 이어질 줄 알았다. 위키백과에서 한자 풀이 45,760개를
  거둬 재보니 **정밀도 5~10%** 였다. 무작위 16개 중 봐줄 만한 것이 1~2개다.

      범유행(汎流行) -> 行 -> 한국은행, 은행     行 이 '다니다' 와 '은행' 으로 갈린다
      면제배갑(綿製背甲) -> 甲 -> 한화갑, 강기갑   한국 인명의 끝 글자가 다 걸린다
      발아(發芽) -> 芽 -> 오승아                 위와 같음
      면회(面會) -> 會 -> 의회, 교회             면회의 대상이 의회일 리 없다

  한자 **한 글자**가 너무 모호하고, 인명이 색인을 오염시킨다. 게다가 정작
  필요했던 `세차`·`독서` 는 위키에 한자 풀이가 **아예 없었다** — 정밀도가
  좋았어도 못 썼다. 같은 문장에서 목적어 자리를 집는 쪽이 훨씬 낫다(아래).

## 된 것

- **정의문에서 '대상' 뽑기** (`build.대상뽑기`, `목적그래프.py`). 목적이 수단을
  제약하는 관계를 원문에서 가져온다. `세차하러 가는데 걸어서 5분 차로 10분이면
  차를 타야 하나` 에 답하려면 '세차의 대상이 차' 를 알아야 하는데, 그것을 사람이
  적는 대신 위키 첫 문장에서 뽑는다.

      "세차는 자동차를 씻는 일이다"  ->  ('자동차', '씻')  ->  .kg

  잰 것: 위키 45,760개 중 유(類)가 동작류인 627개에서 **186개(30%)** 가 뽑혔고,
  표본 12개를 눈으로 봐서 **대략 8할**이 맞았다. `우상숭배->우상` ·
  `할례->포피` · `제설->얼음` · `적분->넓이` · `식분증->배설물`.

  재현율 30% 이고 정밀도가 8할이라 **사람 확인이 필요한 수준**이다. 그것이
  이 프로젝트 모델 그대로다 — 기계가 후보를 내고 사람이 `.kg` 에 올린다.
