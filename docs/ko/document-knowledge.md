# PDF·PPTX 문서 지식 그래프

UI에서 PDF 또는 PPTX를 선택하고 **문서 이해**를 누르면, 원문을 실행하지 않고
페이지/슬라이드 위치가 보존된 주장 후보를 분석한다. 충분한 독립 주장이 있을 때만
세션 전용 overlay에 JSON 지식 그래프를 만든다.

## 만드는 지식

- 정의, 인과, 절차, 한계, 실험·분석 근거, 일반 서술을 별도 유형으로 기록한다.
- 모든 그래프 근거 노드에는 문서명과 `p.N` 또는 `slide.N` 위치를 보존한다.
- 같은 위치의 같은 문장은 한 번만 기록한다.
- 문서 속 명령문은 자료일 뿐 실행 권한이 아니다.

## 보류 기준

텍스트가 거의 없는 스캔 PDF, 그림·표만 있는 슬라이드, 문맥을 잃은 지시어, 또는
검증 가능한 독립 주장이 세 개 미만인 자료는 그래프를 만들지 않는다. UI는 그 대신
OCR·원문·페이지 위치 등 다음에 필요한 자료와 검토 지점을 보여 준다. 이 상태에서
추정으로 사실을 추가하지 않는다.

현재 버전은 PDF의 텍스트 레이어와 PPTX 텍스트 상자를 읽는다. 차트, 도식, 이미지
안의 글자와 슬라이드 애니메이션의 의미는 시각/OCR 해석 단계가 추가되기 전까지
근거로 확정하지 않는다.

CLI에서도 확인할 수 있다.

```sh
python document_kg.py 논문.pdf --out /private/tmp/paper.graph.json
python document_kg.py 발표자료.pptx --report
```
