# 별도 일반화 진단 v2

기존 16문항 기반 개선 뒤 새로운 표현과 조건 조합 14문항을 별도로 고정했다.
파일은 `data/benchmarks/reasoning_challenge_v2.json`이며 SHA-256은
`61c6c9d5f25846e3dd14b419791cf03f50b044223767a73e028cd6d76d9b94e5`다.
평가 전에 이 문항을 위한 실행 코드나 해석 데이터를 수정하지 않았다.
동일한 작업자가 만든 진단이므로 독립적인 블라인드 평가로 주장하지 않는다.

```sh
KG_ENCODER=문자 python bench/dialogue_evaluation.py --dataset data/benchmarks/reasoning_challenge_v2.json --output data/benchmarks/reasoning_challenge_v2_baseline.json
```

결과는 **7/14**다. 분수 연산과 방정식, 한글 수사 수량 계산, 다른 행위자가 등장하는
위치 추적, 예정된 이동, 불충분한 비교의 보류, 숫자만 출력은 통과했다.

실패한 일곱 문항은 모두 웹 조사로 넘어갔다. 표현 순서가 다른 자연어 식,
같은 물건의 장소별 수량, '작다'로 표현한 비교, 활용형이 다른 분류/행위,
명시 원인 독해, 조건문의 대우 추론, 대명사 연결이다. 관계 진단을 각 실패에
첨부했으며, 현재는 해석 단계에서 막혀 추론 규칙까지 도달하지 못한다.
예를 들어 '춤춘다'라는 활용형을 해석하지 못하면 분류 사슬 규칙이 있어도 못 푼다.

평가는 임시 일상추론 팩과 실제 `AppState.turn`을 사용한다. 외부 웹은 빈 결과로
대체해 호출을 기록하며, 브라우저 렌더링과 전체 지식 검색 품질을 검사하지 않는다.
이후 실행기의 문항 시간에는 실패 진단 비용도 포함되므로 과거 실행의 시간과
단순 비교하면 안 된다. 정답 점수의 기준은 바꾸지 않았다.

결론: 기존 세트 11/16과 새 세트 7/14는 표본이 달라 향상·퇴보로 직접 비교할 수 없다.
다만 새 표현에서 해석이 막히는 범위가 여전히 크다. 문장 전체 틀의 추가만으로
일반화를 완성했다고 볼 수 없다. 구성 요소와 관계 해석을 재사용하는 방향의
개선 및 더 넓은 평가가 필요하며 전체 목표는 미완료다.
