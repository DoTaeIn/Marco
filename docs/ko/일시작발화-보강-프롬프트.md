# 일 시작 발화 보강 프롬프트 — 다른 AI 에게 준다

`docs/ko/그래프-저작-프롬프트.md` 를 먼저 주고 이어서 준다. 새 그래프를
짓는 것이 아니라 **이미 있는 그래프를 고치는** 일이다.

왜. 지금은 사실을 대야만 걸린다. `12만원 나왔어` 는 되는데 `밥값 나눠야
하는데` 는 안 걸린다. 사람이 일을 시작할 때 하는 말이 그래프에 없다.

---

# 있는 그래프에 '일 시작 발화' 를 채워 줘

`graphs/*.kg` 를 하나씩 열어, **사람이 그 일을 시작할 때 하는 말**을
목표 노드의 예시로 더한다. 새 노드도 새 엣지도 만들지 마라 — 예시만 는다.

## 무엇이 시작 발화인가

사실을 대지 않고 **하고 싶은 일만 말하는 것**이다.

```
사실 발화(이미 됨):  12만원 나왔어 / 2등을 제쳤다 / 그 곡은 45분짜리다
시작 발화(없음):     밥값 나눠야 하는데 / 지금 몇 등이지 / 연주 얼마나 걸려
```

시작 발화는 **목표 노드**에 붙인다. 그 그래프가 무엇을 해 주는 곳인지를
사람 말로 적는 것이다.

```
[개념]
몫을안다 {원 = 총액 / 인원}: "한 사람이 얼마 낼지 안다" | "몫을 말할 수 있다"
                          | "밥값 나눠야 하는데" | "n분의 1 얼마야"
                          | "나눠서 내려는데" | "각자 얼마씩 내면 돼"
```

## 규칙

**목표 노드에 4~6개**를 더해라. 색인은 노드당 다섯을 가져가므로, **제일
흔하게 할 말을 앞에 둬라.** 뒤로 밀리면 라우터가 못 본다.

**묻는 말과 하려는 말을 섞어라.** `얼마야`(묻기), `나눠야 하는데`(하려는 말),
`각자 얼마씩`(줄인 말) 셋이 다 온다.

**그 그래프에서만 쓰는 낱말을 넣어라.** `얼마야` 만 있으면 정산·대출·보험금이
서로 가져간다. `밥값`, `n분의 1` 처럼 그 일에만 쓰는 말이 있어야 갈린다.

**짧아도 된다.** 목표 노드는 증거가 아니라 다섯 글자 미만은 색인에서
빠진다. 다섯 글자는 넘겨라.

**[무관]도 같이 채워라.** 이웃 그래프의 시작 발화를 넣어 서로 안 뺏게 한다.
정산 그래프라면 `대출 얼마나 나와`, `보험금 얼마 받아` 를 [무관]에 둔다.

## 어느 그래프부터

일상에 가까운 것부터. 정산 · 순위 · 연주 · 라면 · 택배 · 세탁 · 청소 ·
분리배출 · 일정관리 · 길찾기 · 컴퓨터파일 · CCTV · 화재대피.

법·보안 그래프(graph.kg, 음주운전, 취약점분석 등)는 **건드리지 마라** —
회귀 시험이 걸려 있다.

## 검사

한 그래프를 고칠 때마다 돌려라.

```bash
KG_ENCODER=문자 python engine.py --diagnose graphs/<그 그래프>.kg
KG_ENCODER=문자 python engine.py --route "<더한 시작 발화들>"
```

- 더한 발화가 그 그래프로 와야 한다
- **이웃 그래프의 사실 발화를 안 가져가야 한다.** 아래를 같이 물어 확인:
  `12만원 나왔어` · `2등을 제쳤다` · `그 곡은 45분짜리다` · `고마워`

다 고친 뒤 전체를 한 번 재라. 아래가 **떨어지면 안 된다**.

```bash
KG_ENCODER=문자 python routing_benchmark.py --답
KG_ENCODER=문자 python engine.py --regress
```

## 낼 것

1. 고친 그래프 목록과 각각 더한 줄
2. 그래프마다 `--route` 결과 (제 것은 오고 남의 것은 안 온다는 증거)
3. `routing_benchmark.py --답` 의 전후 값
4. **넣을까 하다 뺀 말** — 어느 그래프로 갈지 애매해서 뺀 것들
