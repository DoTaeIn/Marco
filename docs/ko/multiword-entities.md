# 수식어가 붙은 대상과 문장 간 해석

관계 해석 슬롯이 한 단어만 받던 제한을 제거했다. '작은 단추'와 '큰 단추',
'파란 유리 구슬'과 '초록 유리 구슬'을 서로 다른 대상으로 유지한다.
숫자로 주석된 슬롯은 숫자만 받으므로 설명 문장이 수량 안으로 들어가지 않는다.
쉼표·줄바꿈으로 나뉜 관찰과 간략한 수량 서술의 예시도 데이터에 추가했다.

띄어 쓴 대상을 허용하면 새 모호성이 생긴다. '오래된 지도는 작은 서랍에 있었다'는
'지도는'의 조사와 '작은'의 끝을 각각 경계로 보는 두 후보를 낸다. 같은 입력의
다른 명확한 문장과 질문에 등장한 개체 문자열을 대조하여 반복되는 대상을 가진
후보를 선택한다. 모호한 후보끼리 서로 근거를 만들지 않으며, 지지할 다른 문장이
없거나 동률이면 해석을 보류한다. 원문 근거의 위치는 유지한다.

이는 개체 이름 일관성을 이용한 제한적 후보 선택이다. 모든 한국어 구문이나
대명사 해소가 해결된 것은 아니다. 한 문장 안에서 가능한 모든 분할을 탐색하지도
않으며, 서로 다른 표기의 같은 개체를 자동으로 합치지 않는다.

검증 결과:

- 서로 다른 길이의 이름으로 수량 분리·증감, 다단어 이동 대상과 장소, 수량 슬롯의
  오해석 방지, 모호한 후보 보류와 원문 span 보존을 검사했다.
- 기존 관계·수량·시점·학습·정정 회귀와 새 검사 합계 40개 통과.
- 동일 SHA-256의 실제 `AppState.turn` 평가가 8/16에서 9/16으로 개선됐다.
  추가 통과는 다른 색 공의 수량이 섞인 질문이다. 이전 통과 문항은 유지됐다.
- 원자료: `data/benchmarks/dialogue_evaluation_multiword.json`.

평가 문항을 본 뒤 개선한 개발 결과이므로 블라인드 일반화로 주장하지 않는다.
자연어 방정식·한글 수사·불충분한 비교·원인 독해·출력 형식 지시 등은 여전히 남아 있다.
