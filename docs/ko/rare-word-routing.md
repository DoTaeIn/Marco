# 몇 그래프에만 나오는 낱말은 그 자체로 증거다

2026-09-12. 물음에 든 드문 낱말을 라우팅 순위에 얹었다. 바꿔 말하기
**32.0% -> 37.5%**, 근거까지 본 줄 **40.0% -> 49.8%**, 셋 안 **52.5% -> 66.8%**.
대조군과 밖 거절은 안 나빠졌다.

## 어디를 노렸나

라우팅이 틀린 것을 셋으로 갈랐다.

```
정답이 셋 안에 있음    20.5%   <- 근거 라우팅이 여기서 건진다
정답이 셋 밖          47.8%   <- 여기를 손 안 댔었다
```

셋 밖 176건을 뜯어봤다.

| | |
|---|---:|
| 정답 그래프만 물음의 낱말을 갖고, 그것이 더 드묾 | **42.6%** |
| 1등이 더 드문 낱말을 가짐 | 6.2% |
| 정답만 가진 낱말이 아예 없음 | 51.1% |

그리고 그 낱말이 나오는 그래프 수는 **892개 중 중앙 2개**였다.

```
하구 생태를 설명해 줘        정답 해양생태_기초   1등 행동경제학_기초  0.65
빛으로 안 보이는 물질        정답 우주론_기초     1등 미생물_기초      0.53
강수 형태는 대기층의 온도 분포…  정답 기상학_기초     1등 전기_기초       0.60
```

**가르는 낱말이 물음에 있는데 점수가 그것을 무시한다.** 포함도는 '줄의 조각
중 몇 할이 물음에 있나' 라서, 드문 낱말 하나가 흔한 낱말 여럿에 묻힌다.

## 고친 것

색인에 `{드문 낱말: 그 낱말이 나오는 그래프들}` 을 한 번 만들어 붙인다.
892개 중 **둘 이하**에만 나오는 낱말만 담는다.

물음에 그런 낱말이 있으면, 그것을 가진 그래프의 **겨루는 값**을 올린다.
한 물음에서 세 낱말까지만 센다.

```
겨루는 값 = 점수 + 0.12 x 다른노드받침 + 0.20 x 드문낱말수(최대 3) + 0.05 x 쓰임
돌려주는 값 = 점수
```

**순위에만 들어간다.** 점수에 섞으면 그래프마다 값이 달라져 문턱의 뜻이
바뀐다 — `_USAGE_WEIGHT`·`_AGREE_WEIGHT` 와 같은 규율이다. 그래서 밖 거절이
안 깎인다.

무게 0.20 위로는 값이 평평했다(0.20/0.30/0.50/1.00 에서 173·173·174·174).
필요한 만큼만 쓴다.

## 조사를 떼야 신호가 산다

처음에는 겉꼴 그대로 셌더니 `생태는` 과 `생태` 가 다른 낱말이 됐다. 같은
낱말의 꼴마다 따로 세어지면 흔한 낱말이 꼴 때문에 드물어 보이고, 물음의 꼴이
색인의 꼴과 다르면 아예 안 걸린다.

`hangul.drop_particle` 을 새로 뒀다. 뗀 나머지가 두 글자 아래면 안 뗀다 —
`사과` 의 `과` 를 떼면 `사` 가 되고, 한 글자는 조사와 구별할 길이 없다.

| | 겉꼴 그대로 | 조사 떼고 |
|---|---:|---:|
| 안 물음 | 142 | **150** |
| 안 물음 · 셋 안 | 248 | **267** |
| 안 물음 · 근거까지 봄 | 187 | **199** |

## 아직 아닌 것

문서 앞에 예로 든 `하구 생태를 설명해 줘`·`빛으로 안 보이는 물질` 은 **아직
안 고쳐졌다.** 그것들은 드문 낱말이 없는 51.1% 쪽이다. 얻은 것은 다른 곳에서
왔다.

남은 51.1% 는 물음과 정답 그래프가 **낱말을 하나도 공유하지 않는** 자리다.
그 자리는 이 방식으로 못 간다.
