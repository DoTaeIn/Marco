# 시작 발화가 서로 훔치는 것을 고쳐 줘

재보니 목표 노드 예시 30개가 남의 그래프로 간다. 두 가지 원인이다.

## 1. 너무 일반적인 시작 발화

```
길찾기_기초 목표 예시:  "어떻게 가야 해"
→ 화재대피_기초 가 1.00 으로 가져간다
→ '불이야 어떻게 해' 가 길찾기로 간다
```

`어떻게 가야 해`, `얼마야`, `어떻게 해` 처럼 **어느 분야에나 쓰는 말**은
시작 발화가 될 수 없다. 그 분야에서만 쓰는 낱말이 한 개는 있어야 한다.

```
나쁨:  "어떻게 가야 해"
좋음:  "목적지까지 어떻게 가야 해" | "길 어떻게 가야 해"
```

**고칠 것.** 각 그래프의 목표 노드 예시를 훑어, 분야 낱말이 하나도 없는
줄을 찾아 고치거나 지워라. 지우는 것도 답이다 — 어디로 갈지 모르는 말은
없느니만 못하다.

## 2. `~할 수 있다` 예시들이 서로 훔친다

```
청소_기초 가 가져간 것
   0.75  '배출 전에 확인할 수 있다'   (원래 분리배출_기초)
   0.73  '세탁 전에 확인할 수 있다'   (원래 세탁_기초)
   0.73  '녹화 여부를 점검할 수 있다'  (원래 CCTV_기초)
```

이건 시작 발화가 아니라 **원래 있던 시스템 말투 예시**다. `~ 전에 확인할
수 있다`, `~ 여부를 점검할 수 있다` 라는 **틀을 여러 그래프가 공유**해서,
틀만 남고 알맹이가 묻힌다.

**고칠 것.** 목표 노드의 시스템 말투 예시에서 분야 낱말이 앞에 오게 하고,
공유하는 틀을 줄여라.

```
나쁨:  "세탁 전에 확인할 수 있다"     (틀이 대부분)
좋음:  "빨래를 어떻게 할지 정할 수 있다"
```

## 3. 증거 별칭도 사람 말투로

같이 나온 것이다. 아래가 다 미지로 떨어진다.

```
'라벨을 봤어요'    → 세탁_기초 의 라벨읽기 별칭은 '옷 안쪽 라벨을 읽었다'
'연기 발견했어요'  → 화재대피 의 연기발견 별칭은 '복도에 연기가 찼다'
```

**증거 별칭에 사람이 실제로 할 말을 3개 이상 더해라.** 짧은 말, 존댓말,
반말을 섞어라. 저작 규칙 3번이 시작 발화만큼 증거에도 필요하다.

## 검사

```bash
KG_ENCODER=문자 python routing_benchmark.py --답
```

지금 값은 **답함 71.9% · 밖 거절 21/25** 다. 떨어지면 안 된다.

그리고 아래로 서로 안 훔치는지 확인해라. 각각 제 그래프로 가야 한다.

```bash
KG_ENCODER=문자 python engine.py --route \
  "밥값 나눠야 하는데" "택배 보내려는데" "빨래하려는데" "청소 시작해야 하는데" \
  "분리배출 어떻게 해" "일정 잡아야 하는데" "길 어떻게 가야 해" "파일 어디 있지" \
  "라면 끓이고 싶은데" "불이 났는데 어떻게 대피해" "CCTV 확인하고 싶어"
```
