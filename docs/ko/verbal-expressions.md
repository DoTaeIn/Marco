# 말로 표현한 식의 연산 그래프 연결

`verbal_expression.py`는 `data/semantic/verbal_expressions.json`에 선언된
문법을 재귀적으로 적용해 숫자·미지수·연산 트리를 만든다. 그 트리를 기존
`expression_graph.solve`에 전달하여 분수와 일차방정식을 계산한다.

'어떤 수의 네 배에 6을 더하면 34가 돼. 그 수는 얼마야?'는 7로 계산되며,
숫자와 답의 대응표는 없다. 중첩 배수, 빼기, 나누기도 같은 연산 노드를 쓴다.
수사는 기존 데이터 기반 숫자 해석을 사용한다. 입력 길이·재귀 깊이·작업량을
제한하고, 원문 전체가 문법에 맞지 않으면 이 해석 경로는 후보를 만들지 않는다.
기존 상태 엔진의 원문 재해석 검증도 그대로 거친다.

검증: 수식 조합·분수·기존 의미 파서 및 실제 UI의 연구 미호출 검사 20개 통과.
동일 고정 대화 평가가 10/16에서 11/16으로 개선됐다. 추가 통과는 자연어
일차방정식 문항이다. 원자료는 `data/benchmarks/dialogue_evaluation_verbal.json`.

이것은 개발 진단을 보고 개선한 제한적 문법 해석이며 블라인드 평가가 아니다.
등식의 종결 표현, 미지수를 가리키는 표현 등은 현재 선언된 문법 범위에 한정된다.
임의의 서술형 수학 문제·자유 독해·조건부 논증을 완성한 것으로 보지 않는다.
기존 고정 평가의 사건 표현·전제 부족·역추론·원인 독해 실패는 계속 남아 있다.
