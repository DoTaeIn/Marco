# 물음의 말끝도 계산한다

2026-09-11. 관계 추론이 물음을 적힌 꼴 하나로만 알아듣던 것을 고쳤다.
같은 물음을 사람이 쓰는 여러 말끝으로 물어 **9/35 에서 35/35** 가 됐다.
얼린 잣대는 안 움직였다.

## 무엇이 문제였나

서술문의 말끝은 오래전부터 문법으로 만들어 왔다. 물음만 빠져 있었다.

```python
if "query" in example["meaning"]:
    raise ValueError("question_inflection_requires_speech_act_model")
```

막아 둔 이유가 있었다. 서술 어미를 물음에 붙이면 **묻던 말이 단정하는 말이
된다.** `누가 더 커` 와 `누가 더 크다` 는 같은 어간에 같은 활용 기계를 쓰지만
하는 일이 다르다. 그래서 통째로 뺐다.

대가가 이랬다.

```
누가 더 커?        풀림
누가 더 큰가요?     못 품
누가 더 크니?       못 품
누가 더 큽니까?     못 품
```

**반말로 물으면 풀고 존댓말로 물으면 못 풀었다.**

## 고친 것

말의 결을 지키면서 말끝을 계산하려면, **물음의 말끝을 따로 선언**하면 된다.
물음은 물음 어미로만 실현한다.

```json
"question_endings": ["informal", "polite", "question_ni", "question_jyo",
                     "question_ga", "question_ga_polite",
                     "question_formal", "question_kka"]
```

새 어미 여섯은 기존 연산(`append`, `coda_suffix`)만으로 적었다. 그림씨·움직씨·
과거가 갈리는 자리는 `background` 어미가 쓰던 꼴을 그대로 따랐다.

```
크 (그림씨)   커 · 커요 · 크니 · 크죠 · 큰가 · 큰가요 · 큽니까 · 클까
있 (있음)     있어 · 있어요 · 있니 · 있죠 · 있는가 · 있는가요 · 있습니까 · 있을까
옮기 (움직씨)  옮겨 · 옮겨요 · 옮기니 · 옮기죠 · 옮기는가 · 옮깁니까 · 옮길까
```

물음 예시에는 **어간과 갈래만** 적는다. 말끝은 문법이 만든다.

```json
{"text": "하루와 모래 중 누가 더 커",
 "inflection": {"stem": "크", "kind": "descriptive",
                "tense": "present", "ending": "informal"}}
```

## 문이 둘이었다

첫째는 위의 `raise` 였고, 둘째는 뜻을 고르는 자리에 있었다.

```python
if normalization and ("query" in meaning or ...):
    continue                      # 정규화된 후보는 물음이면 무조건 거절
```

물음이 제 활용표를 갖기 전에는 맞는 규칙이었다 — 그때 물음에 닿는 정규화는
낡은 접미사 지름길뿐이었고, 그것은 말의 결을 지킨다는 보장이 없다. 이제
**제 활용표에서 나온 정규화**(`example_index` 가 붙은 것)만 통과시키고,
지름길은 여전히 물음의 말끝을 못 바꾼다.

`받으면 안 됨` 이 그대로인 것이 중요하다 — 근거가 없거나 물음이 아닌 넷이다.
**말끝을 넓혔다고 아무거나 받지는 않는다.** 시험이 이것을 따로 고정한다.

`bench/question_endings.py --적힌말끝만` 은 선언과 주석을 떼고 고치기 전 자리를
다시 만든다. 없어진 코드를 상상하지 않고 같은 자리를 다시 밟는다.

## 이것이 무엇을 고치지 않았나

**라우팅은 그대로다.** 얼린 잣대 여덟 줄이 한 칸도 안 움직였다 — 바꿔 말하기
31%, 노드 17.8%. 관계 추론과 라우팅은 말을 맞추는 방식이 다르다. 라우팅은
별칭에 대한 포함도로 재고, 여기서 고친 것은 예시 문장의 활용이다.

같은 병의 세 번째 자리를 고친 것이지, 네 번째(라우팅)는 아직 남아 있다.

| 자리 | 무엇이었나 | 결과 |
|---|---|---|
| 대화 이해 | `phrases` 가 글자까지 같아야 걸렸다 | 12/74 -> 74/74 |
| 의도표 | `어디서 쓰` 는 적히고 사람은 `어디서 써` 라고 쳤다 | 죽은 갈래가 살아났다 |
| 관계 추론 | 물음이 활용 확장에서 빠져 있었다 | 9/35 -> 35/35 |
| 라우팅 | **아직** | 안 물음 31.0% |

## 아직 아닌 것

`지금 구슬은 몇 개야` 꼴 두 예시는 주석을 못 달았다. 지정사 `이다` 가 열린
소리 뒤에서 `야` 로 줄어드는 자리인데, 그 규칙이 `활용` 에 없다. **없는 활용을
지어내지 않는다** 는 규율대로 비워 뒀다. 지정사를 문법에 들이면 그때 붙는다.
