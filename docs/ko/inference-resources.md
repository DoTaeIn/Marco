# 규칙 추론 자원 측정

`python bench/inference_resources.py --output 결과.json`은 양의 Horn 규칙으로
관계 사슬을 확장한다. 무관한 사실 256개를 섞고 모든 도달 가능 삼중항을 검사한다.
결론뿐 아니라 선택된 근거 기록 전체의 SHA-256도 전후 비교한다.

| 사슬 길이 | 기존 중앙 시간 | 개선 중앙 시간 | 기존 Python 할당 피크 | 개선 피크 |
|---|---:|---:|---:|---:|
| 12 | 15.175ms | 1.505ms | 273,848B | 211,544B |
| 24 | 91.474ms | 8.184ms | 1,265,440B | 347,824B |

원자료: `data/benchmarks/inference_resources_baseline.json`,
`data/benchmarks/inference_resources_indexed.json`. 두 경우 모두 전후 근거 해시가 같다.
시간은 tracemalloc 없이 3회 실행한 중앙값이며, 메모리는 별도 실행의 tracemalloc
피크다. 전체 프로세스 RSS나 앱 전체 지연, 일반 지능 성능을 뜻하지 않는다.

기존에는 변수 하나를 결합할 때마다 모든 사실을 다시 훑고 중간 조합 전체를
리스트에 보관했다. 이제 주체·관계·대상별로 현재 라운드의 색인을 만들고,
이미 고정된 값의 가장 작은 후보 묶음을 훑는다. 중간 조합은 필요할 때 하나씩
생성한다. 입력 순서를 유지하여 동일한 첫 근거를 선택하며, 그래프·조합 수 제한도
유지한다. 규칙이나 문제별 정답은 추가하지 않았다.

별도의 작은 완전탐색 검사와 입력 순서를 바꿔 비교하여 변수 관계명, 반복 변수,
순환 관계에서도 결론·근거가 같은지 검사한다. 긴 규칙의 본문 자체, 전체 UI 자원,
모델 로딩 및 대화 저장 비용은 별도 측정이 남아 있다.
