# 검증된 숫자 답변의 출력 지시

검증된 계산 결과를 출력하는 단계에서 '숫자만 답해' 요청을 적용한다.
질문 끝의 명시적인 지시와 완전한 숫자 답변 형태가 모두 맞을 때만 서술형 어미와
단위를 제거한다. 예를 들어 `8 + 3을 계산하고 설명 없이 숫자만 답해.`의 답은 `11`이다.
수학 계산과 검증 근거는 그대로 유지한다. 요청 표현과 답 형태는
`data/semantic/output_contracts.json`에 있고 엔진과 UI가 같은 함수를 사용한다.

UI의 정서 접두 표현은 이 경우 붙이지 않는다. 인용문·코드 안의 예시와
'숫자만 답하지 마'는 지시로 쓰지 않는다. '16일 수도 있습니다', '16 또는 17입니다'
처럼 불확실하거나 복수 값인 답변에서 숫자를 억지로 추출하지 않는다.

실제 엔진·UI의 정수/분수 답변, 인용 및 부정 지시, 불확실한 답변 보존과
정서·기존 상태 경로 회귀를 포함한 13개 검사가 통과했다.
고정 대화 진단은 9/16에서 10/16으로 개선되었으며, 문항 SHA-256은 같다.
원자료: `data/benchmarks/dialogue_evaluation_output_contract.json`.

범위는 지원하는 명시적 지시와 이미 얻어진 숫자 답변이다. 모든 출력 형식이나
자연어 지시의 조합을 지원하는 것은 아니다. 관계 파서가 지시까지 포함한 문장
전체를 이해하지 못하면 이 출력 단계가 그 해석 실패를 대신 해결하지 않는다.
일반 독해·자연어 방정식 등 남은 실패는 계속 별도 개선해야 한다.
