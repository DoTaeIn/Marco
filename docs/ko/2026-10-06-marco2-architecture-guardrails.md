## 2026-10-14 기존 Hypomnema의 Context qualification 복사 보관

기존 `trace/from_turn.py` 한 owner가 같은 턴 실제 Context 반환의 v2 qualification만 기존 `output_created.payload.context_qualification`에 연결한다.
Trace는 보관 운반을 맡으며 뜻·세계 진실·완전한 pending-set 인증이나 Context/Memory의 책임을 대신하지 않는다. 새 로그·저장·추론 엔진과 기본 그래프 변경은 없다.
보관은 exact plain JSON 깊은 복사, 정규 UTF-8 해시와 한정 답변 원문의 해시다. 화면 일치는 raw UTF-8로 계산하고 기존 strip 기반 trace SHA/reply SHA는 그대로다.
메타데이터 최대65536바이트·8192노드·깊이32, 답변 원문24576바이트를 선행 제한한다. 인식된 손상은 unavailable이며 값을 자르거나 위조하지 않는다.
없는/v1/미지 메타데이터는 기존 형태를 유지한다. 너무 큰 top-level dict는 미인식이며 absence를 검증 성공으로 해석하지 않는다. 실제 append/I/O 오류는 기존대로 전달한다.
첫 실제59/60과 준비 예외1건·추가 차단9건의 한계를 보존했다. 이는 합성 adapter/Context-shaped 입력을 실제 DialogueTrace/record_turn/Ledger 저장 경로로 운반한 검사이며 새로운 Model.session 의미 평가가 아니다.
보관된 복사는 당시 Context 반환값의 복사일 뿐 parser/projection 전체 상태·native 원출력 본문·객체 정체성·독립 현실 진실을 증명하지 않는다.
실행기에서 불가능했던 선택 메모리 rlimit 요청은 별도 정확 검토로 제거하여 memory-cap/동등성을 주장하지 않는다. CPU/file/fd 제한과 사용자·private·제품 자료 및 network/fork 차단을 유지하고 필요한 시스템 런타임 읽기만 명시했다.
선택 그래프의 native unknown 역할 생산/guard/archive 연결은 별도 작은 계약으로 검토하며 broad guard 해제나 학습 기록의 KG 실행 규칙 전환으로 우회하지 않는다.

## 2026-10-13 승인된 Context의 두 사실과 누적 보류 범위

사용자가 직접 승인한 Context 수정 범위에서 선택 GraphView의 optional fact-batch-policy와 known-evidence-policy-v2를 읽는다.
L9는 원문을 쪼개거나 Context.turn을 추가 호출하지 않는다. 한 입력의 직접 긍정 불변 이항 사실은 최대2개이며 기존 span·순서·실제 해석 출처를 확인한다.
누적 보류 원문·순서·전체 digest를 보존하고 실제로 질의를 막는 원문과 직접 archived support를 결속한 경우에만 선택 선언의 한정 답변을 낸다.
v2의 최대8개는 이 override의 증거 한도이며 전체 대화를 중지시키는 규칙이 아니다. 대상과 무관한 기존 질문 경로는 유지한다.
기존 `_blocked_by`와 `_turn` 본문·snapshot ABI·추론/저장/로그 책임을 대체하지 않는다. 원본 Context는 별도0444 백업하고 새 Context도0444로 유지한다.
기존 v1 응답 shape·옛 팩·기본 선택을 보존한다. 새 언어/정책은 명시 선택 새 팩에만 추가했다.
첫35의 잘못된 전제와 첫22 채점기의 필드 오류를 원점수와 함께 보존한다. 독립 기록 감사는 재채점이나 새 성능 시험이 아니다.
native typed 미해석 입력의 자연 생산은 현재 연결되지 않았다. qualification은 실제 result/trace에 있으나 저장된 대화 문자열/Hypomnema의 완전한 복사·parser/projection 당시 상태 인증은 입증하지 않았다.
UI의 ‘생각 과정’은 기존 해석 진단을 접는 표시 변경이다. 실제 답변과 의미 확인 질문·명시 승인까지 숨기거나 자동 승인하지 않는다.

## 선택한 그래프가 기준이다

이해, 후보 해석 검증, 추론, 답변 구성과 학습은 선택한 그래프·모델의 선언을
사용한다. 도메인 지식, 어휘, 관계의 뜻, 적용 규칙과 특정 정답을 코드에 고정해
성공 사례를 만들지 않는다. 공통 알고리즘과 저장 형식의 구현은 엔진이 맡는다.
언어와 의미의 연결도 선택한 그래프·모델이 제공한 선언을 따른다.

다른 그래프를 선택하면 그 그래프의 표현·관계·규칙·응답 선언이 적용되어야 한다.
빠진 선언을 개발용 기본 그래프나 다른 세션의 지식으로 대신 채우지 않는다.
그래프별 학습과 대화 기록의 식별자를 검증해 이전 그래프의 의미가 새 그래프에
몰래 적용되지 않게 한다. 학습한 예시 그대로의 답을 저장해 전이로 발표하지 않는다.

## 보류는 국소적인 확인이다

모르는 부분은 미해결 문제로 남기고 필요한 설명을 사용자에게 묻는다. 그 부분을
사실로 확정하지 않는다. 이미 알고 있는 맥락과 독립적으로 근거가 있는 다른
질문·진술은 계속 처리한다. 확인 답이나 새 표현을 받으면 같은 문제를 이어서
해결한다. 한 번의 보류 때문에 모든 응답을 막거나 새 대화로 버리는 동작은
기본 처리로 인정하지 않는다.

## 모듈의 책임

언어 층은 표면 표현과 의미의 변환 및 발화를, 지식 수집 층은 자료와 출처 관찰을,
추론 층은 그래프 검증과 근거가 있는 결론을 맡는다. 학습 층은 후보 검증과 승인을,
저장 층은 저장 형식과 식별자 검사를, 런타임 층은 세션 연결과 실행 순서를 맡는다.
검색 출처 원문은 인용 자료로 보존하며 완성된 답변을 대신하는 문장 선택기로
사용하지 않는다. 답은 결론의 의미에서 구성하고 다시 읽어 의미를 확인한다.

## 이번 감사에서 발견한 미완료 항목

첫 세션 연결 코드는 개발용 기본 모델을 고정 선택했다. 선택한 모델을 직접 받고
전체 자산 식별자·해석기·학습 저장소의 변경 이력을 검증하는 연결을 감사·통합했다.
서로 다른 선언의 의미·규칙·답변·학습 전이와 교차 그래프 거절을 확인했다.
이 유한 검사만으로 모든 그래프의 임의 대화·자가학습을 입증한 것은 아니다.

새 `marco.conversation` 배치는 원래 런타임의 세션 책임과 맞지 않아 핵심 후보
감사 뒤 `marco.runtime.learning_dialogue`로 이동했다. `knowledge/ingest`의 검색 답변 코드도 추론 호출과
문장 구성까지 맡았으므로 `marco.runtime.research`와
`marco.language.realizer.source_answer`로 나누어 감사·통합했다. 시간 해석을
발명하지 않는 선언 검사도 포함했다. 기존 구조 안에서 책임을 바로잡은 수정이다.

원래 해석을 잃은 과거 기록 때문에 모든 새 응답을 막는 세션 초안도 발견했다.
검증된 의미 기록으로 안전하게 처리할 수 있는 대화는 계속하고, 과거 해석이
필요한 작업만 확인하는 수정과 검사를 통과했다. 입력 이해가 모두 해결됐다는
뜻은 아니며 미해결 문제를 설명받아 다시 입력하는 유한 시연까지 확인했다.

원래 구조 안에서 해결할 수 없는 문제가 실제로 생기면, 필요한 변경과 이유,
재현 근거 및 원래 구조 안의 대안을 소유자에게 먼저 알린다. 현재 발견한 항목은
기존 역할 경계 안의 수정 대상으로 판단했으며 핵심 철학 변경을 승인하지 않았다.

## 답변과 학습의 출처 기록

소유자는 절대적인 진실이라는 표현에 매달리기보다 대답이 나온 관찰·가정·규칙과
배운 출처를 남기도록 요청했다. 기존 `marco.trace`의 Hypomnema는 JSONL 사건
기록과 답변에서 입력으로 거슬러 올라가는 근거 연결을 제공한다. `reported`,
`observed`, `assumed`, `inferred`, `verified` 등은 구분해서 기록한다. 검증은
기록한 기준을 통과했다는 뜻이며 모든 현실에서 참이라는 선언으로 사용하지 않는다.
근거를 남긴 것만으로 오해한 입력이나 잘못된 계산을 정당화하지 않는다.

추적 기록은 명시적으로 활성화한다. 새 M2 세션에 fsync ledger를 전달하면
답변·가르치기·철회·검색 시도가 기존 Hypomnema에 기록된다. 학습의 가르친
내용·검증·승인·철회 출처는 기존 학습 저장소에도 남는다. 답변의 실제 근거에
있는 관찰 식별자와 과거 해석·당시 학습 head를 연결하며, 실제 선택된 학습
후보를 식별하는 수집기는 일반 관계 사실의 실제 답변 근거에 한해 연결했다.
조건·사건·발화·외부 출처를 포함한 전체 수집은 아직 남아 있다. 설치된 후보
전체를 실제 사용한 근거로 표시하지 않는다. 별도의 추론 엔진이나 중복 로그
체계를 만들지 않는다.

추적 계약 v2는 감사·통합했다. 선택한 구성 요소는 호출자가 명시하며 호스트
기본값을 선택의 증거로 사용하지 않는다. 검증 기준과 내부 처리 사건을 답변의
근거 연결에 포함하고, 입력을 먼저 저장하며 부분 쓰기·저장 실패·중단을 기록한다.
실제로 전달하지 못한 답을 전달했다고 표시하지 않는다. 설치된 학습 이력과
실제로 쓴 후보는 구분하며 수집기가 없는 정보는 `provenance_incomplete`로 남긴다.
M2 세션 연결 후보는 학습 성공 뒤 문맥 갱신 실패 시 검사 기록 누락을 독립
재현해 수선한 다음 감사·통합했다. 저장 성공과 로그 실패, 학습 저장과 세션
저장 실패는 따로 기록하며 수행하지 않은 검사를 만들지 않는다. 정확한 사용
학습·발화·가정·외부 출처 수집의 부족은 계속 명시한다.

입력 성분 조합도 선택한 모델의 `predicate_frames` 선언을 따르는 작은 경로로
감사·통합했다. 같은 문장을 두 모델에서 다른 관계·방향으로 읽고 각 모델의
규칙과 답변을 사용했다. 선언된 부정·가정·역할 표지를 이름이나 수식으로
흡수하는 결함은 독립 재현 뒤 수정했다. 원문 전체를 읽지 못하면 해당 입력을
확인 대상으로 남기며 도메인 단어를 코드에 고정하거나 기본 그래프로 대체하지
않는다. 일반 언어팩 선언과 폭넓은 대화 적용은 아직 남아 있다.

2026-10-06 추가 연결은 기존 책임 안에서 감사·통합했다. 선택한 원래 예문의
의미와 역할·활용 선언에서 새 어순을 읽는 `predicate-frames-v2` 경로를 실제
대화에 연결했다. 기존 등록 문장과 부정·가정 범위를 보존하고, 그래프 교체와
가르친 표현의 다른 예시 사용·재시작·철회를 확인했다. 일반 언어팩에는 이
선언을 자동으로 추가하지 않았으며 모든 자연어를 이해한다는 주장도 하지 않는다.

실제 답변 근거의 원래 관찰 ID와 해석 revision은 저장 전부터 선택하고 재시작
뒤에도 보존한다. 추적을 활성화한 세션의 저장 성공 답변에는 기존 Hypomnema의
`provenance.learning_dependencies`로 부분 출처를 자동 연결한다. 원래 학습
후보·규칙 revision·가르친 대화와 턴·당시 승인 기록을 연결하며, 뒤의 교체나
철회로 과거 출처를 덮어쓰지 않는다. 답변에 쓰이지 않은 다른 절의 후보는
포함하지 않는다. 출처 수집 오류는 유한한 누락 표시로 남기며 정상 답변과
저장을 막지 않는다. `used_learning` 전체 수집과 현실 진실 검증으로 승격하지
않고, 서명 없는 로컬 승인 기록이라는 한계를 유지한다.

인터넷의 실제 제목 검색과 반환된 첫 주소의 본문 수집도 확인했다. 해당 한 번의

내용을 이해한 것을 구분한다. 위 변경이나 개발 검사 숫자를 봉인 시험 또는

사실·부정·조건을 반환하며 실제 선택 선언과 원문 해시를 부분 수집한다. 관찰의
