# AGI 최소 지식 그래프

[`graphs/graph_AGI_최소지식.kg`](../../graphs/graph_AGI_최소지식.kg)는 범용 지능의
완성 선언이 아니라, 여섯 종류의 지식이 **근거 사례 → 구체 결론 → 상위 영역**으로
이어지는지 검사하는 작은 공개 지식팩이다. 답변은 언어 모델이 즉석 생성하지 않고,
그래프 노드에 적힌 검증 문장을 선택한다. 현재는 직접 검증 사례 22개를 수록한다.

## 다루는 영역

| 영역 | 검증하는 결론의 예 |
| --- | --- |
| 물리·시공간 상식 | 유리잔 파손 가능성, 불의 화상 위험, 용기 크기, 아침·점심 순서, 서울–부산 도보 시간 |
| 사실 지식 | 대한민국 수도, 산술, 지구 공전, 훈민정음, 프랑스 수도 |
| 절차 지식 | 조리 순서, 프로그램 뒤 테스트, 조립 전 설명서·부품 확인 |
| 추론·인과 | 부등식의 전이, 상관과 인과의 구분, 원인과 결과의 선후, 반사실 가정 |
| 마음의 이론·사회성 | 짧은 답장으로 감정을 단정하지 않기, 농담의 맥락, 배려 표현, 틀린 신념 가능성 |
| 메타인지 | 근거가 없는 주가 예측과 정보 없는 진단을 확정하지 않고 추가 정보를 요청하기 |

## 재현 가능한 검사

```sh
KG_ENCODER=문자 python -m unittest -v test_agi_minimum_knowledge.py
KG_ENCODER=문자 python kgpack.py --pack NAI.kgpack --root .
python kgpack.py --list NAI.kgpack
```

`test_agi_minimum_knowledge.py`는 대표 문항이 의도한 노드에 연결되어 사람이 읽을 수
있는 검증 문장을 실제로 돌려주는지, 그리고 실시간 질문을 지어내지 않는지를 확인한다.

문장 표현이 크게 달라지는 일반화, 최신 사실, 개인별 의료·법률·재정 판단은 이 작은
팩의 범위가 아니다. 그런 요청은 별도 도메인 그래프 또는 원문 조사·승인 흐름이 필요하다.

## 벤치마크와의 관계

MMLU, ARC, HellaSwag, CommonsenseQA는 넓은 범용성을 재는 외부 데이터셋이다.
이 저장소에는 그 원문·정답·라이선스 데이터가 포함돼 있지 않으므로 이 그래프의
핵심 25문항(및 선언된 표현 변형) 점수는 그 어떤 공식 벤치마크 점수도 아니다. 외부 벤치마크를 주장하려면
버전이 고정된 원본 데이터, 선택지 처리 방식, 채점 스크립트, 데이터 누출 점검을
별도로 추가해야 한다.

신경망 문장 인코더는 선택 사항이다. 패키지 UI와 위 재현 검사는 모델 다운로드가
필요 없는 `KG_ENCODER=문자`를 사용한다. 신경망 모델을 명시적으로 쓰려면 해당
모델이 로컬에 설치돼 있어야 하며, 없을 때 문자 모드 결과를 신경망 결과로 표기하면
안 된다.
