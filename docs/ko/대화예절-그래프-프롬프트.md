# 대화예절 그래프 프롬프트 — 다른 AI 에게 준다

`docs/ko/그래프-저작-프롬프트.md` 를 먼저 주고, 이어서 아래를 준다.
분야가 특이해서 규칙 몇 개가 다르게 적용된다.

왜 필요한가. 지금 `고마워` 를 물으면 색인 최고 점수가 0.12 라 아무 데도
안 붙는다. 일을 다루는 그래프는 50개인데, 그 일을 **하는 동안 사람이 하는
말**을 받을 그래프가 하나도 없다.

# 대화예절 그래프를 만들어 줘

`graphs/graph_대화예절.kg` 하나. 앞서 준 저작 규칙을 그대로 따르되,
아래가 이 그래프의 특수한 점이다.

## 무엇을 담나

일을 처리하는 그래프들 **곁에서** 사람이 하는 말이다. 주제가 아니라 **결**이다.

- 인사 — 안녕하세요 / 안녕 / 반가워요
- 감사 — 고마워 / 고맙습니다 / 감사해요
- 사과와 수습 — 미안 / 아 잘못 말했다 / 그거 말고
- 맞장구와 확인 — 응 / 맞아 / 그렇구나 / 알겠어
- 되묻기 응답 — 무슨 뜻이야 / 다시 말해줘 / 잘 모르겠어
- 마무리 — 됐어 / 그만 / 수고했어

## 이 그래프만의 규칙

**목표를 억지로 만들지 마라.** 다른 그래프는 요건을 채워 목표에 닿지만,
인사에는 닿을 목표가 없다. 목표는 `대화를이어간다` 정도로 두고 요건을
한두 개만 둔다. `--diagnose` 가 '증거가 없다 — 공유 라이브러리다' 라고
알려 주면 그대로 두어도 된다.

**짧은 말이 많다.** `응`, `맞아`, `고마워` 는 두세 글자다. 색인은 다섯
글자 미만을 버리지만 **증거 노드는 짧아도 남기므로**, 이 말들을 [사례]에
두고 근거관계로 이어라. 그러면 라우터가 본다.

**말투를 아주 많이 적어라.** 다른 그래프는 노드당 3개면 되는데 여기는
**5~8개**를 적어라. 인사는 사람마다 제일 다르게 말하는 자리다.
색인이 노드당 다섯까지 들고 간다.

**[무관]에 일 이야기를 넣어라.** 이 그래프가 다른 그래프의 질문을 가로채면
안 된다. `12만원 나왔어`, `2등을 추월했다`, `파일 권한이 뭐야` 같은 것을
[무관]에 두어 밀어내라. 이게 이 그래프에서 제일 중요한 자리다 —
어디에나 걸리는 그래프는 없느니만 못하다.

**대사가 이 그래프의 알맹이다.** 다른 그래프는 판정이 알맹이지만 여기는
답 문장 자체가 일이다. 공들여 적어라.

## 넣지 말 것

- 잡담을 이어 가는 말(`날씨 좋죠?`) — 이 엔진은 화제를 만들지 않는다
- 감정 위로 — `graph_감정대화_기초.kg` 가 이미 있다. 겹치지 마라
- 자기소개(`저는 …입니다`) — 사실이 아닌 것을 그래프에 적는 셈이다

## 검사

```bash
KG_ENCODER=문자 python engine.py --diagnose graphs/graph_대화예절.kg
KG_ENCODER=문자 python engine.py --route "고마워" "안녕하세요" "12만원 나왔어" "2등을 제쳤다"
```

- `고마워` · `안녕하세요` 가 이 그래프로 와야 한다
- **`12만원 나왔어` · `2등을 제쳤다` 는 이 그래프로 오면 안 된다** —
  오면 [무관]을 더 채워라

## 낼 것

1. `.kg` 파일
2. `--diagnose` 출력
3. 위 `--route` 네 줄의 결과 (가로채지 않는다는 증거)
4. 인사 → 일 이야기 → 감사로 이어지는 3턴 대화 기록
