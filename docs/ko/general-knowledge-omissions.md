# 생활 지식 그래프에서 의도적으로 뺀 범위

아래 항목은 사실 확인·지역 규정·개별 상태가 필요해 일반 지식 그래프의
공리나 사례로 적지 않았다. 해당 질문은 검증된 원문 또는 담당 기관 안내가
필요하다.

- CCTV 영상의 열람 권한, 보관 기간, 제공 절차, 사건의 사실 판단
- 지자체·아파트별 분리배출 요일과 품목별 세부 기준
- 화재 현장의 구조·진압 방법·개인의 위험 상황별 판단
- 의류·세제·표면별 세부 사용량과 혼합 가능성
- 실시간 교통량, 대중교통 운행, 택배 도착 시각과 배송 상태
- 파일을 실제로 삭제·덮어쓰기·외부 전송하는 행동
- 일정 참가자의 실제 가능 시간과 타인의 개인 일정

추가할 지식은 원문 출처와 적용 범위를 확인한 뒤, 별도 `.kg`로 분리한다.
