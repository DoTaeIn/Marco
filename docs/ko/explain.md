# 자기 지식으로 채우는 대화 AI

텍스트 폴더를 넣으면 지식 그래프가 되고, 그 그래프와 대화한다.
**GPU를 쓰지 않는다.** 질문 하나에 CPU 0.2초.

```bash
python build.py 내폴더                    # 폴더 -> 지식그래프.json
python explain.py 내폴더/지식그래프.json         # 대화
```

## 1. 폴더에 글을 넣는다

`.txt` 나 `.md` 를 넣으면 된다. 주제는 아무거나. `README*` 로 시작하는 파일은
설명서로 보고 건너뛴다.

**대목을 나누는 기준은 자동으로 고른다:**

| 글의 모양 | 나누는 단위 |
|---|---|
| `제1조(제목) …` | 조문 |
| `## 제목` (마크다운) | 절 |
| 그 외 | 빈 줄로 나뉜 문단 |

**제목을 잘 달수록 그래프가 좋아진다.** 제목에 있는 말이 그 대목의 주제가 되어
`설명함` 관계가 생긴다. 제목이 없으면 문단 첫머리를 대신 쓴다.

```markdown
## 멸치육수
멸치와 다시마를 찬물에 넣고 끓인다. 다시마는 끓기 시작하면 건져야 쓴맛이 안 난다.
```
→ `멸치육수` 가 이 대목에서 다뤄지고, `멸치`·`다시마`·`쓴맛` 을 함께 다룬다.

## 2. 그래프를 짓는다

```bash
python build.py 내폴더
python build.py 내폴더 --min 3        # 3개 대목 이상 나온 개념만
python build.py 내폴더 --out 내.json
```

`kiwipiepy` 로 복합명사를 뽑는다(`정당`+`방위` 가 아니라 `정당방위`).
CPU만 쓰고 문장당 0.33ms.

## 3. 대화한다

```
> 김치찌개 어떻게 만들어?
  김치찌개 는 김치찌개 / 김치찌개 에서 다룹니다.
  그 대목은 감칠맛, 국물, 김치, 돼지고기, 돼지고기목살 를 함께 다룹니다.
  멸치 를 설명할 때도 나옵니다.

> 자동차 수리 방법 알려줘
  그건 이 그래프에 없는 이야기입니다.
```

**모르는 것은 모른다고 한다.** 그래프에 없는 내용은 나오지 않는다.

**질문 종류를 가려서 다른 문장을 고른다.** 같은 개념이라도 묻는 것이 다르면
답이 달라야 한다 — `음주운전 뭐야` 는 면허 조문을, `음주운전 처벌` 은 벌칙 조문을 준다.

| 묻는 말 | 고르는 것 |
|---|---|
| `뭐야` `설명` | 정의 |
| `처벌` `형량` `벌금` `무슨 죄` | 벌칙 조항 |
| `얼마` `금액` `수수료` | 액수가 적힌 문장 |
| `누가` `누구` | 주체가 적힌 문장 |
| `언제` `기한` `며칠` | 기간·시점 |
| `어떻게 해` `절차` | 방법·절차 |
| `어떤 경우` `요건` | 조건 |
| `왜` `무슨 근거` | 이유 |
| `어디` / `누가 써` / `뭐랑 관련` | 위치 / 쓰는곳 / 이웃 |
| `A랑 B 무슨 관계야` | 경로 |

```
> 저작권이 뭐야
  제10조(저작권) ①저작자는 … 저작인격권 … 저작재산권 … 를 가진다
  — 저작권법 제10조(저작권) 외 11곳

> 저작권 침해하면 처벌받아?
  제136조(벌칙) ① 저작재산권 … 침해한 자는 7년 이하의 징역 또는 1억원 이하의
  벌금에 처하거나 이를 병과할 수 있다 — 저작권법 제136조(벌칙) 외 11곳
```

벌칙 조문은 문서 맨 뒤에 몰려 있어 그냥 담으면 후보에도 못 든다. 그래서 개념마다
'어떻게 처벌하나' '얼마인가' 를 말하는 문장을 한 줄씩 따로 챙겨 둔다.
개념 7,195개 중 1,593개가 벌칙 문장을 들고 있다.

**관계를 물으면 지어내지 않는다.** 바로 이어진 것이 없으면 이어지지 않았다고
말한다. `같은조문` 을 두 다리 건너면 저작권과 음주운전도 이어지므로 쓰지 않는다.
대신 같은 대목에 함께 나오면 그 대목을 댄다:

```
> 정당방위랑 긴급피난 무슨 관계야
  정당방위 와 긴급피난 은 이어지지 않지만 민법 제761조(정당방위, 긴급피난) 에 함께 나옵니다.

> 저작권이랑 음주운전 무슨 관계야
  저작권 과 음주운전 은 그래프에서 이어지지 않습니다.
```

## 관계는 두 가지뿐이다

| 관계 | 뜻 |
|---|---|
| `설명함` | 그 대목의 제목이 A 이고 본문에 B 가 나온다 |
| `같은대목` | 한 대목에 A 와 B 가 함께 나온다 |

**둘 다 검증 가능한 사실이다.** "A 가 B 를 함의한다" 같은 해석을 지어내지 않는다.
그래서 환각이 없고, 그래서 추론도 못 한다 — 아는 것만 말한다.

## 법령을 채우려면

```bash
python 법수집.py 대한민국헌법 형법 민법 근로기준법
python build.py 법지식
```
위키문헌에서 원문을 받는다. **판본에 조문이 빠져 있을 수 있다** —
형법의 경우 75개 조문이 없었다. 완전한 원문은 법제처 Open API(무료, 키 필요)가 낫다.

## 알아둘 것

**글의 어휘와 사람의 어휘가 다르다.** 형법 조문에는 `과잉방위` 라는 말이
한 번도 안 나온다 — 조문은 "방위행위가 그 정도를 초과한 때" 라고 쓴다.
사람이 쓰는 말로 물으면 못 찾을 수 있다.

메우는 방법은 두 가지다:
1. 그 말이 나오는 글을 폴더에 더 넣는다 (해설서·요약본)
2. `개념망` 에 관계를 적는다 — `과잉방위 -상위-> 방위행위` (`개념엣지`)

**규모.** 개념 7천 개 · 엣지 37만 개까지 확인했다.
벡터 준비 18초(1회), 질문 중앙 170ms · 최대 300ms. 그 이상은 재보지 않았다.
질문 시간의 대부분은 발췌 후보(최대 8문장) 인코딩이다 — 그래프를 키워도 거의 안 늘어난다.
