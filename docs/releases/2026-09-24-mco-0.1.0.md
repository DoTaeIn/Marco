# mco 0.1.0

The first release of `mco` on PyPI: <https://pypi.org/project/mco/0.1.0/>.
Published 2026-09-24 from the GitHub release `mco-v0.1.0` by the repository's
trusted-publishing workflow (`.github/workflows/publish.yml`), which runs
`tests/test_mco_package.py` before it builds. Files on PyPI:
`mco-0.1.0-py3-none-any.whl` (50,181 bytes) and `mco-0.1.0.tar.gz`
(54,418 bytes). Sizes and dates from the PyPI JSON API
(`https://pypi.org/pypi/mco/json`), read 2026-09-24.

## What the package is

A stable Python API and command line for MARCO-compatible reasoning models,
`.mco` files. Code written against `mco` never imports MARCO's internal
modules, so it keeps working while the engine and the model format change.

```bash
pip install mco
```

| Part | What |
| --- | --- |
| `mco.load`, `Model.run`, `Model.session`, `Model.reason`, `Model.reset` | open a model; one utterance in a conversation; isolated conversations; a self-contained problem as facts plus a question |
| `mco.inspect`, `ModelInfo` | a model's metadata without running anything |
| `mco.compile` | build a `.mco` from a MARCO source tree or a `.kgpack` |
| `mco.benchmark` | accuracy and latency on fixed cases |
| `Result` | `answer`, `status` (`answered`, `observed`, `needs_input`, `unknown`, `rejected`, `pending_approval`), `evidence`, `trace` |
| errors | one hierarchy under `mco.MCOError`; a backend's own exceptions are wrapped, never raised as they are |
| `mco` command | `compile`, `inspect`, `run`, `benchmark`, `backends`; exit codes 0 to 3 |
| backends | `marco-kgpack`, which runs a MARCO checkout; `mco-native`, a placeholder that recognises the native format and refuses it |

The names and signatures in `mco.__all__`, the `Result` fields, the `Status`
values, the error classes and the command line are the stable surface (API
version 1). The contract and how to write a backend: [docs/mco/api.md](../mco/api.md).
The user guide, which is also the PyPI project page: [docs/mco/README.md](../mco/README.md).

## What it needs

| For | Needs |
| --- | --- |
| `import mco`, `mco.inspect()`, `mco inspect`, `mco backends` | Python 3.10 or newer. No dependencies |
| running a model | `pip install "mco[marco]"` (adds `numpy` and `pillow`) and a MARCO checkout, found through `marco_root=`, `MCO_MARCO_ROOT`, `sys.path`, or the checkout `mco` was installed from |
| a model to run | the preview model `MARCO-1-preview.mco` (27,200,481 bytes, 905 graphs, English and Korean packs) on the GitHub pre-release *MARCO 1 · Preview 1* ([notes](2026-09-24-marco-1-preview-1.md)), or `mco compile` over a checkout |

```bash
pip install "mco[marco]"
git clone https://github.com/DoTaeIn/Marco
export MCO_MARCO_ROOT=$PWD/Marco
curl -LO https://github.com/DoTaeIn/Marco/releases/download/Marco/MARCO-1-preview.mco
mco run MARCO-1-preview.mco "12만원 나왔어" "3명이야"
```

## What it cannot do yet

- **Run without MARCO.** The engine is not on PyPI; the only runnable backend
  imports it from a checkout.
- **The native format.** The `.mco` file of this release is a compatibility
  container, a deterministic ZIP around an unmodified MARCO pack
  (`format: mco-compat v0`). The native MCO Format 1 with overlay and snapshot
  is frozen until MARCO 1 passes its gate; `mco` recognises a native file by its
  magic prefix and raises `UnsupportedFormatError` instead of misreading it.
- **Structured facts.** `reason()` accepts `mco.Fact` objects and mappings, but
  the MARCO backend raises `UnsupportedInputError` for subject, predicate and
  value facts; only sentences work.
- **A model's language is fixed when it is compiled.** English unless
  `mco compile --language styles/한국어.json`. `reason()` reads its facts in
  that language: the Korean example of the user guide is answered by a Korean
  model and held by an English one.
- **Composed replies on every path.** MARCO's state dialogue composes every
  reply from a meaning and checks it by parsing it back (340 of 340 replies on
  the frozen dialogue exam, `docs/ko/dialogue-gate-2026-09-22/composition-after-w3.json`).
  Answers from the knowledge-graph route are still the lines the graphs'
  authors wrote.
- **MARCO 1 itself.** The engine behind the package has not passed its own
  gate: 21 of 108 answerable turns on the frozen unseen dialogues against the
  90% it needs (`docs/ko/dialogue-gate-2026-09-22/after-w3.json`). See the root
  [README](../../README.md).
