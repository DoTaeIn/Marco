# MARCO 1

A reasoning engine that answers only from evidence it can point to, composes
every sentence it says from a proven meaning, and holds when nothing grounds an
answer. No language model runs anywhere in it. The owner declared the MARCO 1
gate passed on 2026-10-01 and put MARCO 1 in release freeze
([freeze decision](../ko/2026-09-22-freeze-decision.md), "Gate declared, release
freeze"). MARCO 1 is a completed first-generation architecture with stated
limits, not a target for further capability work; that work is M2.

The model file is built from the release commit with the repository's own CLI
([mco guide](../mco/README.md)), from a clean checkout:

```sh
python -m mco compile . -o MARCO-1.mco --name MARCO-1 --format native   # MCO Format 1.1
python -m mco compile . -o MARCO-1-compat.mco --name MARCO-1            # the 0.1.0 compatibility container
```

The same input gives a byte-identical file. On the release branch at `ae65094`
both files hold 904 graphs and 52 assets (the English and Korean language packs,
one axiom file and 49 files of learned aliases), with English as the model's
language.
The native file also holds the graphs as node and edge tables (8,231 nodes,
6,323 edges) and a rule table of 6 rules. A working checkout may hold a 905th
graph, `graphs/graph_목적_자가검사.kg`, which `purpose_graph.py` writes and git
ignores; a file built there differs from one built from a clean checkout.

A model's language is fixed when it is compiled. The English model holds Korean
statements as unread; a Korean model is built with
`--language styles/한국어.json`.

## Effort

`MARCO_EFFORT` (0 to 3, default 3) bounds how many candidate readings are tried
for a sentence that does not read at first. It never loosens a check. On the
frozen exam at `650efc9`
([re-verification](../ko/2026-09-30-reverification-baseline.md), last section):

| Effort | 0 | 1 | 2 | 3 |
| --- | --- | --- | --- | --- |
| Answerable turns right, of 108 | 63 | 67 | 97 | 98 |
| English, of 54 | 30 | 33 | 53 | 54 |
| Korean, of 54 | 33 | 34 | 44 | 44 |
| Wrong turns | 0 | 0 | 0 | 0 |
| Violations | 0 | 0 | 0 | 0 |

Effort levels 4 (multi-hop graph grounding) and 5 (bounded multi-hypothesis
search) are not in MARCO 1.

20 of the 151 in-domain statements were read. The one wrong answer

## What changed since Preview 1

Preview 1 (tag `Marco`, `826900f`, 2026-09-24): 21 of 108 answerable turns, 1
wrong; 339 of 340 replies composed; 146 of 149 parsed reasoning questions. Since
then, 163 commits on `main`'s first-parent line up to `c8ad9a5`, by theme:

- **Reading as candidates, and effort.** A sentence that does not read at first
  gets candidate readings, each checked against the conversation's state and
  ranked by a declared order of checks (state, reasoning, grammar, context,
  cost); the top one is taken only when it clearly beats the runner-up, a tie
  asks and no survivor holds (round 5, `3475f4f`; round 7 amendments `da949e9`,
  `f3e9a28`). The effort setting bounds that search (`2ccd19c`). The reader
  returns a partial reading whose open slots are grounded in the state
  (experiment 7, `46427c5`). Understanding work ran as seventeen logged
  experiments on 2026-09-29 ([experiment log](../ko/2026-09-29-experiment-log.md)),
  after understanding rounds 4 to 6.
- **The conversation identity graph.** Holders, things and places are nodes with
  stable ids, with alias and count edges carrying their turn and evidence;
  statements, questions and corrections are grounded on those nodes and the
  string-key helpers are gone (decision `2e79631`; steps 1 to 3, `762e2dc` to
  `c128040`; [conversation-graph.md](../architecture/conversation-graph.md)).
  The exam went from 90 to 98 of 108 on it.
- **Corrections.** A correction finds its event by holder and thing node and
  revises it in place (`b7ca278`); the answer after it cites the correction turn,
  never the withdrawn wording (`13d8965`); a correction that says the transfer
  went the other way swaps giver and receiver, with or without names
  (`030d04c`, `fa4afa0`); a correction whose statement was never read is held
  (`55849b6`).
- **Safety fixes**, each turning a possible wrong or unsupported answer into a
  hold: a transfer recorded with a stale count (`18b9f53`); a scope word over one
  holder (`a18c617`); an unread turn that names its holder by a pointer
  (`65fcb7f`); an unread turn that names a thing (`2ed290c`, the SVAMP wrong
  answer); a container and its content as one thing (`ebe95e5`).
- **Speaking.** Why answers are said from the trace graph's why chain in both
  languages (`d082278`); recipient corrections are named, and the Korean user is
  addressed by the honorific (`89b20b6`). The trace ledger, Hypomnema: an
  append-only ledger whose events name their parents (`2143d3b`).
- **The MCO format.** MCO Format 1, a binary file with stable ids and the base
  identity in its manifest (`c6d4e70`), and Format 1.1 with node, edge and rule
  tables (`269997f`); the Persistent Overlay Infrastructure, its store (`43f5d4d`)
  and its application at the next turn with no recompile (`5987ed5`);
  conversation snapshot and restore (`f844401`). Storage infrastructure only:
  none of it makes MARCO change its own knowledge. The `mco` package was published
  as 0.1.0 on PyPI; 0.2.0 is drafted
  ([mco 0.2.0](2026-10-01-mco-0.2.0.md)).
- **Layout.** Fifty-three whole-file modules moved from the root into packages
  (goal S4, `63f3b32` to `ee1390f`).

## Limitations

The owner's list for MARCO 1:

- **Narrow language and domain coverage.** The state dialogue covers who holds
  how many of what: holdings, gains, uses and transfers, and questions of counts,
  totals and comparisons, in the English and Korean sentence forms it was built
  on. No gate measures anything outside it. On the frozen exam 10 of 108
  answerable turns stay held, all Korean.
- **Text written by other people is mostly not read.** The SVAMP result above: 1
  of 70 in-domain problems answered, 20 of 151 in-domain statements read. Reading
  real text is M2.
- **No autonomous learning.** MARCO 1 makes no rule, adds no node, edge or graph
  from a dialogue, and promotes no self-repair and no web or document reading.
  The graph engine stores an alias for an existing node only after a person says
  yes.
- **No effort level 4 or 5.** Multi-hop graph grounding and bounded
  multi-hypothesis search are M2.
- **Persistent overlays are infrastructure, not self-learning.** An overlay
  applies graph and rule changes that a person states or approves through an
  explicit call naming the approver; nothing in MARCO proposes or approves a
  change by itself ([overlay.md](../architecture/overlay.md)).

Smaller limits:

- The engine does not read the tables of a Format 1.1 file on the running path:
  it parses the graph source text kept in the file when the model opens.
- An unfinished knowledge-graph dialogue does not survive a snapshot resume; its
  question is asked again ([snapshot.md](../architecture/snapshot.md)).
- Overlay rule changes reach only the base rule table.
- Not run on Windows: the release checks, the native format, overlays and
  snapshots were run on macOS only.
- The frozen dialogue exam is no longer fully unseen by the development process:
  its failure classes were read by structure and counts, never its sentences.
  This is why the fresh exam is scored once at the release.
- Graph answers are the lines the graphs' authors wrote, in the graph's language;
  every graph is Korean except `graphs/graph_en_bill_split.kg`.

## Run it

Python 3.10 or newer and a MARCO checkout.

```sh
pip install -e ".[marco]"
python -m mco inspect MARCO-1.mco
python -m mco run MARCO-1.mco "Minsu has five apples, and Jiyeon has two." "Minsu gave Jiyeon two." \
    "How many does Jiyeon have now?" "Where is that person?" "Actually, the one given was one, not two."
```

Recorded on the release branch at `ae65094`, in a fresh process, the same from
the native and the compat file:

```
Recorded. Jiyeon has 2 apples.
  status: observed
Recorded. Minsu gave Jiyeon 2 apples. Now Minsu has 3 apples and Jiyeon has 4.
  status: observed
4 apples.
  status: answered
This conversation never stated the location of Jiyeon. So I did not answer.
  status: needs_input
I changed the amount in the same event "Minsu gave Jiyeon two." from 2 to 1. No new event was added. Now Minsu has 4 apples and Jiyeon has 3.
  status: observed
```

The Korean dialogue on a model compiled with `--language styles/한국어.json`:

```
> 민수는 사과 다섯 개, 지연은 두 개가 있어.
  반영했습니다. 민수 사과는 5개, 지연은 2개입니다.
> 민수가 지연에게 두 개 줬어.
  반영했습니다. 민수가 지연에게 사과 2개를 줬습니다. 이제 민수 사과는 3개, 지연은 4개입니다.
> 지연은 지금 몇 개야?
  4개입니다.
> 아까 준 건 두 개가 아니라 한 개야.
  같은 사건 "민수가 지연에게 두 개 줬어."의 수량을 2개에서 1개로 고쳤습니다. 새 사건은 더하지 않았습니다. 이제 민수 사과는 4개, 지연은 3개입니다.
```

Other entry points are in the root [README](../../README.md#quick-start).
