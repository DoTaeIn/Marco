# W2-1: what the realizer now says, and what is left for the parsing side

From: goal W2 (realizer round 2), branch `realizer-r2`.
For: goal G3 (understanding round 3), which owns `styles/*.json` and the parsing,
repair, matching and correction code in `engine.py`, `marco/reasoning/context.py`.
No template string has to change for W2; this note says what W2 relies on.

## 1. Pack strings W2 reads

- The repair label is read from the pack's own `context_replies.repaired`
  template: the word it encloses in `[` `]` (`marco/language/realizer/*.json`,
  lexicon `repair`, `from_pack`). G3.7's 수선 → 수정 rename in `styles/한국어.json`
  therefore reaches every composed sentence without a realizer change. Keep the
  label enclosed in `[` `]` in `repaired`; without it the why-answer falls back to
  a wording with no label ("이 가운데 고쳐 읽은 말" / "Of these, I read differently").
- The `context_replies`, `답못함` and `repaired` / `repair_*` / `explain_*`
  templates are no longer spoken on any turn the realizer plans; they remain
  the engine's fallback sentence (`result["answer"]` before `realize()`), used
  only when a turn has no plan. Rename them freely.
- Scope and correction-target choices are taken from the pack's `범위답` and
  `정정대상답` (first word of each entry) and carried as `choices` in the meaning.

## 2. Meaning fields W2 added at the result-building sites (carve-out)

`marco/reasoning/context.py`: every hold, ask and refusal return now carries
`meaning = {act, reason, …}`; answered turns carry `asked` (the question's own
triple before a pointer was resolved) and, for sums and comparisons, `kind`
(`total` | `more`) with `subjects`/`value` or `winner`/`than`. If G3 adds a new
hold reason, give it a `meaning` with `act` and `reason`; without a plan in
`marco/language/realizer/meaning.json` it is passed through and the
composition gate counts it.

## 3. Optional, parsing side

- Bare `왜` / `왜요` and "what did you change?" are read by the realizer's own
  declared follow-ups (`follow_ups` in each realizer file) before the parser.
  Declaring `왜` as a `why_last` example in `styles/한국어.json` would make the
  parser read it too; nothing breaks either way.
- Replies still passed through (answers, not holds, none met on the four sets):
  the UI's chat reply (`input_understanding.dialogue_reply`), response_composer
  answers, graph-session lines, causal and concept answers. Listed in the W2 report.
