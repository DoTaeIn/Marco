## What step 1 gives

`marco/reasoning/identity.py`, `ConversationGraph`; `ReasoningContext.conversation_graph()` builds it from the
replayed facts (cached per observations, fills and carried part). Nothing reads it yet: no reply changes in step 1.

| Call | Returns |
| --- | --- |
| `graph.nodes` | `{id: {"id", "kind": holder/thing/place, "name"}}`; ids `h1`, `t1`, `p1`, stable within the conversation, carried in the snapshot, never reused |
| `graph.id_of(kind, name)` | the node id of a key name, or None |
| `graph.find(text, kinds=None, fold=None, forms=None)` | node ids one of whose aliases is `text` |
| `graph.aliases` | `{"node", "text", "form", "turn"}`; forms `key`, `title`, `possessive`, `relation`, `number`, `pointer`, `reply` |
| `graph.counts[(holder, thing)]` | `{"holder", "thing", "value" (int or None), "origin": said/computed, "turns"}` |
| `graph.holders_of(thing)`, `graph.things_of(holder)`, `graph.value(holder, thing)` | by node |
| `graph.of_key(key)` / `graph.key(holder, thing)` | the replay's string key ↔ (holder, thing): the one bridge while facts are keyed by strings |
| `context._said_around_key(parser, text, holder)` | the aliases a statement gave a holder (title before or after, possessive, relation word) |

## Asked of the statement side (step 3)

1. **The split moves to the reader.** Today the graph splits a fact's key by the longest holder key (the facts carry
   no split). Please have the reader name each fact's holder and thing (for instance `row["parts"] = {"holder": …,
   "thing": …, "place": bool}` on the fact, or the slot values the example matched); the graph will use it and stop
   splitting strings. `tests/test_conversation_graph.py::test_a_list_of_two_things_of_one_holder_is_one_holder_node`
   is a strict expected failure until then (`보늬는 연필 세 개, 컵 두 개를 …` makes `컵` a holder).
2. **Your candidate steps** (`_read_other_keys`, `_read_unsaid_thing`, `_read_wrong_thing`, `_read_without_adjunct`,
   `_shaken_by_unread`) can take their candidates from `holders_of` / `things_of` / `find` instead of key strings;
   a re-keyed statement is then an alias edge of the existing node (form `key`, its turn), not a second key.
3. Tell G7-Q (as `G7-5.md`) any field you need that is not above.
