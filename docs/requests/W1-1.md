# W1-1 — the turn result must carry its meaning, not only its sentence

From: W1 (realizer). To: owner of `marco/reasoning/context.py` (G1 now). Lines at be25630.

## Why

`realize(meaning, intent, language)` receives the turn result. For answered
turns the result carries the answer fact (last transition `{"fact": [s, p, v]}`),
so the realizer composes those today. For every other turn the result carries
only the finished sentence, built from a `context_replies` template. The
realizer cannot compose what it is not given, so it passes those sentences
through unchanged. §12 steps 3b, 5 and 6 (goal item R2) are all in this group:

| Step | Site | What the result lacks |
| --- | --- | --- |
| 3b | `_missing_premise` 2298, returns a string; callers 3301, 2087 | subject and relation of the missing premise |
| 5 | `_explain_last` 2108 | correction utterance, old/new amount, rule ids (only display names are used), question for `explain_answer` |
| 6 | `_answer_other_than` 2162 | the pointer word, the excluded referent, the candidates (`transitions: []`) |
| 4 | `_correct_by_reference` 2214, reply at 2293 | old/new amount, corrected event; the `corrected` record at 2719 likewise |
| records | 3361–3370 | which act (`observed_state`, `scope_settled`, `filled_role`, `observed`) produced the sentence |

## Request

Add one key, `"meaning"`, to every result dict that has an `"answer"`. Language-free
values only: ids, triples, the user's own words, numbers. No sentence built by us.

    "meaning": {"act": <id>, "reason": <id or absent>, "conversation": <stable id>, ...fields}

Fields per site (names are the realizer's contract, `marco/language/realizer/meaning.json`):

1. 3301 / 3369 (unresolved question, missing premise):
   `{"act": "refuse", "reason": "premise_missing", "subject": subject, "relation": predicate}`.
   `_missing_premise` can return `(text, {"subject": ..., "relation": ...})` or store the pair.
   Same for the companion path at 2087, plus `"answer_language": <companion pack path>`.
2. 2108 `_explain_last`:
   `{"act": "explain", "kind": last["kind"], "question": last.get("question"),
     "evidence": evidence, "rules": [fact predicate ids, e.g. "count_remove"],
     "changes": changes, "repairs": [{"source": r["source"], "reading": r["reading"]}],
     "correction": {"utterance": record["utterance"], "before": record["before"],
                    "after": record["after"], "old": record["reference"]["old"],
                    "new": record["reference"]["new"]}}` (correction only when kind is correction).
   `rules` must be the ids (`name`), not `rule_names[name]`.
3. 2162 `_answer_other_than`, every `unresolved(...)` call:
   `{"act": "ask", "reason": key, "word": request["excluded"], "excluded": excluded,
     "candidates": candidates or others}`.
4. 2214 `_correct_by_reference`: success
   `{"act": "correct", "event": source.strip(), "old": request["old"], "new": request["new"],
     "new_event": false, "changes": changes}`; each `reply(key, ...)` as
   `{"act": "hold", "reason": "reference_" + key, "said": said, ...values}`.
5. 3353 answered: `{"act": "inform", "query": 풀린물음[0]["triple"], "unit": <declared unit of the
   matched question example, if any>}`. The unit matters: the legacy render carries
   `개` / `명` / `권` from the question example; the realizer otherwise uses its declared
   default counter for `count`.
6. 3361–3370 observed: `{"act": "record", "reason": "observed_state" | "scope_settled" |
   "filled_role" | "observed", "turn": len(self.observations) - 1, "changes": this_turn}`.
7. Every other `replies[key].format(**values)` site: `{"act": "hold", "reason": key, **fields}`
   with the values the template received, under these names: `말`→`said`, `목록`→`items`,
   `자리`→`role`, `정한값`→`declared`, `온값`→`given`, `남은`→`rest`, `물음`→`question`,
   `몸통`→`body`, `범위`→`scope`, `값`→`value`. Plans exist today for `invalid`,
   `contradiction`, `unread_event`, `reference_no_event`; the rest pass through until declared.
   The over-bound repair hold built in `_turn_reply` (2758–2766):
   `{"act": "hold", "reason": "repair_over_bound"}` (the reports are already in `result["repair"]`).
8. `"conversation"`: any id stable for one `ReasoningContext` (e.g. assigned in
   `__init__`, kept in `snapshot`/`restore`). Expression learning (R7) is scoped by it;
   without it learned expressions stay off in the live seam.

## After it lands

No change at the call site 2731. The realizer composes every result that has
`meaning` and passes through the rest; `tests/language/test_w1_r2_section12.py`
already runs the §12 steps against these exact fields (`tests/language/w1_harness.py`
attaches them inside the test, computed as each engine method computes its sentence)
and will run live once they are real.

Optional, later: `realize` also returns a hold flag (the realizer never emits a
sentence that fails its semantic check); the call site can then set
`status = "unresolved"` instead of keeping `answered` over a held sentence.
