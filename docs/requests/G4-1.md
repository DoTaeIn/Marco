# G4-1: the packs now read what W3-1 asked for; seven W3 tests pin the old packs

From: goal G4 (understanding round 4), branch `understanding-r4`.
For: the realizer's owner (goal W3's files, `tests/language/test_w3_round4_meanings.py`).

W3-1 asked the packs to read, among others, `I have 3 apples.` and `Tove has no plums.`
G4 batch 1 declares both in `styles/english.json` (가진쪽꼴 `self`, and the zero examples
`Haru has no marbles`, `Haru doesn't have a single marble`, ...). Two tests written for the
pack as it was now fail for that reason alone:

| Test | Pinned | Now |
| --- | --- | --- |
| `test_english_holds_the_user_until_the_pack_reads_the_first_person` | the check fails on `I have 3 apricots.` and the reply is held | the pack reads it as `[I apricots, count, 3]`; the reply is said |
| `test_a_zero_the_pack_does_not_read_as_none_is_said_in_digits[english-*]` | the English zero is said in digits (`0 quinces.`) | the pack reads `has no quinces` as the count 0, so `count_none` is said |

Batch 3 (Korean) adds, in `styles/한국어.json`: places with 에는 (`북쪽 창고에는 상자가 5개
있다` → `[북쪽 창고 상자, count, 5]`), the zero idiom (`하나도 없다` → count 0, 말자리.zero_idiom),
and titled holders (`린드 씨` → `린드`, 가진쪽꼴 name_titles). So these fail too, for the same
reason: `test_a_place_holds_things[한국어-None-result3/4]` (now `북쪽 창고에는 5개 있습니다`),
`test_a_zero_the_pack_does_not_read_as_none_is_said_in_digits[한국어-result2]` (now `하나도
없습니다`), and `test_a_named_holder_the_pack_reads_back_otherwise_is_held`.

Asked: flip these seven expectations to the "pack reads it" side (the stand-in `ReadsAs`
cases already cover what the plans say then).

Also asked (a new plan): the recipient correction (`They went to me, not Arthur.`,
`아, 동훈이 아니라 연서한테 줬어요.`) is an in-place revision whose meaning is the `revise`
act with `field: recipient`, `old_holder`, `new_holder` (the amounts of a `correct` act are
numbers, so it is not said as one). The `revise` plan says it today by quoting the sentence
before and after; a plan that names the two receivers would read better.

Meaning fields: G4 uses W3-1's names (`holders`, `kind`, `said`; `vague_count`; the
count `"0"`; the keys `I` and `나`).
