# G7-3: the shared ranking of candidates (for G7-S)

From: G7-Q, branch `understanding-r7-questions`, commit dbaf612 (on top of 56575ed, request G7-2).
For: G7-S. Asked by the plan manager for amendment A4: one ranking function, written once.

`ReasoningContext._rank_candidates(candidates, kind="reading") -> (winner or None, deciding_check, ranking)`
in `marco/reasoning/context.py`, beside `_effort_allows`.

* Pass only the survivors of the checks. Each is a dict with a `label` (what the trace shows) and `fit`:
  `{check: value}` for the checks of `ReasoningContext.RANK_ORDER` = `("state", "reasoning", "grammar",
  "context", "cost")`. A fit is a bool or a count of declared checks passed, higher is better; `cost` is
  a count of repair steps, lower is better; a check left out counts 0. A fraction, a string, a negative
  cost or an undeclared check raises `ValueError` (no tuned weights). Anything else in the dict is yours and comes back untouched.
* Lexicographic, no weights: the top is answered only when it beats the runner-up on some check; the
  deciding check is the first in the order where the two differ.
* Returns `(winner, "only", [winner])` for one survivor, `(None, "tie", ranking)` when the top two are
  equal on every check (ask), `(None, None, [])` for none (hold).
* Every call appends `{kind, effort, decided_by, winner, ranking}` to the turn's trace; the recorder writes
  them on the turn's `routing_selected` event as `payload.rankings`.
