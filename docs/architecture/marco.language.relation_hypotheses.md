# marco.language.relation_hypotheses

This L1 module proposes uncommitted relation meanings for a currently unread single-word predicate. It belongs to the existing language layer and reuses the native seed frame compiler and role binder. It does not select a lexical truth, produce an ordinary answer or install learning.

`propose_relation_hypotheses(parser, text, *, projection, binding, candidate_limit=16)` returns original source, a detached existing SourceParserSnapshot binding, all in-bound policy/span candidates and local gaps. The caller must supply a genuine current-unread witness, fresh native parser and actual selected package projection; JSON coherence is not ownership authentication. Selected graph policies, role markers, head grammar and actual frame/provenance determine candidates. No implicit default graph or domain dictionary is used.

A private parser and counterfactual string replace one unknown span with each declared canonical predicate. The unchanged binder checks the entire declaration. Emitted assumed facts preserve policy/frame sources, virtual execution trace and separately remapped original spans. They never become accepted readings or evidence that the word is true. Graph view pin and learning memory head remain separate. Missing policy is a local unavailable gap; overflow returns no silent top-N subset.

Current scope: positive asserted flat binary frames; source512chars/40words/40split units, policies16 and candidate_limit1–16. Additional reference_forms, scalar/compound hypotheses and internal binder ambiguity are held. Complete candidate semantics are in tools/marco2_relation_hypotheses_dev/SOURCE-CONTRACT.md and its exact source repair records.
