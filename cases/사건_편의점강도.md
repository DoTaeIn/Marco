# 편의점 야간 알바생 폭행 사건

## 사건
- 역할: 검사
- 목표: 정당방위
- 법리: legal/법리_형법21조.kg
- 개념망: legal/개념망_한국어.kg

새벽 2시, 편의점에 흉기를 든 강도가 들어와 금품을 요구했다.
알바생(피고인)이 저항하는 과정에서 강도가 중상을 입었다.
변호인은 정당방위를 주장한다.

## 증거
- CCTV: 시시티비, 매장 영상, 녹화 화면
- 목격자진술: 목격자, 증인 진술, 옆 손님 진술
- 진단서: 진단서, 피고인 진단서, 피고인 병원 기록
- 피해자진단서: 피해자 진단서, 피해자 상해 진단
- 압수된흉기: 압수된 흉기, 압수물, 압수된 칼
- 근무일지: 근무일지, 근무 기록, 교대 기록
- 현장사진: 현장 사진, 현장 감식 사진
- 피고인진술조서: 피고인 진술조서, 피고인 조서

## 사실

### 흉기소지
- 증거: CCTV, 압수된흉기, 현장사진
- 말: 흉기를 들고 있었습니다 / 칼을 꺼냈습니다 / 무기를 소지했습니다
- 충족: 침해의부당성, 침해가 현재 진행 중이었다, 막기 위해 필요한 행위였다

### 금품요구
- 증거: CCTV, 목격자진술
- 말: 돈을 내놓으라고 했습니다 / 금품을 요구했습니다 / 계산대를 열라고 했습니다
- 충족: 침해의존재, 침해의부당성

### 출구차단
- 증거: CCTV, 현장사진
- 말: 출입문을 막고 있었습니다 / 나갈 길이 없었습니다 / 도망칠 곳이 없었습니다
- 충족: 공격이 아직 끝나지 않았다, 막기 위해 필요한 행위였다
- 부정: 도망칠 수 있었다

### 선제공격
- 증거: CCTV
- 말: 피고인이 먼저 공격했습니다 / 의자를 먼저 집어 들었습니다 / 먼저 손을 댔습니다
- 부정: 침해가 현재 진행 중이었다

### 반복가격
- 증거: CCTV
- 말: 쓰러진 뒤에도 계속 때렸습니다 / 넘어진 사람을 여러 번 가격했습니다
- 충족: 지나친 방어였다, 공격은 이미 끝난 뒤였다

### 피고인부상
- 증거: 진단서
- 말: 피고인이 다쳤습니다 / 피고인이 상처를 입었습니다 / 피고인도 부상당했습니다
- 충족: 위험을 인식하고 대응했다

### 피해자중상
- 증거: 피해자진단서
- 말: 피해자가 크게 다쳤습니다 / 전치 12주가 나왔습니다
- 충족: 지나친 방어였다

### 야간영업
- 증거: 근무일지
- 말: 새벽 2시였습니다 / 심야 시간대였습니다 / 야간 근무 중이었습니다
- 충족: 야간이라 공포에 질렸다

### 공포진술
- 증거: 피고인진술조서
- 말: 무서웠다고 진술했습니다 / 죽는 줄 알았다고 했습니다
- 충족: 위험을 인식하고 대응했다, 야간이라 공포에 질렸다
