# 출제 안내문: 세금 지식 (외부 출제자용)

이 글을 그대로 출제자에게 준다. 출제자는 이 저장소의 코드, 수업, 이전 문항을 보지 않는다. 일곱째부터 열여섯째 묶음이 이 안내문(개수와 말투 지시만 조금씩 다름)으로 만들어졌다. 돌려받은 `questions`를 `probes/tax16_e2e_20261126/C.json`을 복사한 파일의 `questions` 자리에 넣는다(`probes/assemble_tax_set.py`가 이 일을 하고 형식을 검사한다).

---

당신은 독립된 시험 출제자입니다. 규칙 기반 한국어 질의응답 시스템을 시험할 질문을 한국어로 씁니다. 시스템이 어떻게 만들어졌는지 모르는 상태로 써야 하므로, **어떤 파일도 읽거나 검색하지 마십시오**. 필요한 것은 아래에 다 있습니다. 시스템에 맞춰 주려고 하지 마십시오.

## 시스템

아래 지식 14개를 가지고 있고, 그 지식에 대한 질문에 답합니다. 확실하지 않으면 답하지 않습니다. 답이 없는 질문에 답하면 틀린 것으로 셉니다.

## 지식 (대상 / 속성 / 값)

```
F01 일반과세자 / 세율 / 10%   (부가가치세 일반세율)
F02 일반과세자 / 과세기간 / 6개월
F03 개인일반사업자 / 신고횟수 / 연2회
F04 법인사업자 / 신고횟수 / 연4회
F05 일반과세자제1기확정신고 / 신고기간 / 7월1일~7월25일
F06 일반과세자제2기확정신고 / 신고기간 / 다음해1월1일~1월25일
F07 간이과세자 / 신고기간 / 다음해1월1일~1월25일
F08 사업자등록 / 신청기한 / 사업개시일부터20일이내
F09 사업자등록 / 신청경로 / 홈택스
F10 국세상담센터 / 상담전화 / 126
F11 종합소득세일반신고 / 신고기간 / 다음해5월1일~5월31일
F12 2025년귀속종합소득세일반신고 / 신고기한 / 2026년6월1일
F13 성실신고확인서제출자 / 신고기한 / 다음해6월30일
F14 2026년제1기부가가치세확정신고 / 신고기한 / 2026년7월27일
```

대상 이름은 띄어쓰기 없는 한 덩어리로, 위에 적힌 그대로 씁니다. 대상의 다른 이름: 2025년귀속종합소득세일반신고 = 2025년분종합소득세일반신고, 국세상담센터 = 국세청상담센터. 속성의 다른 말: 세율 = 부가가치세율, 일반세율.

## 할 일: 질문 80개

질문은 형태 제약이 없습니다. 실제 사람이 세무 상담 창구, 전화, 메신저에서 묻듯이 쓰고, 문항마다 다른 사람이 쓴 것처럼 들리게 하십시오. 사람들이 실제로 자주 쓰는 아주 흔하고 평범한 말투의 질문을 절반쯤, 드물고 독특한 말투의 질문을 절반쯤 섞습니다. 각 질문에는 위 지식만 보고 신중한 사람이 할 답과 근거 지식 번호를 적습니다.

| kind | 개수 | 내용 |
| --- | --- | --- |
| `direct` | 6 | 속성 낱말을 써서 또박또박 묻는 질문 |
| `short` | 6 | 조사를 빼고 짧게 묻는 질문 |
| `natural` | 40 | 속성 낱말(과 그 다른 말)을 **쓰지 않고** 동사나 일상 말로 묻는 질문. 대상 이름은 그대로 씁니다. 14개 지식을 고루 다룹니다. |
| `check` | 4 | 값을 대고 맞는지 묻는 질문, 절반은 틀린 값. 값은 사람이 쓰듯 자유롭게 적어도 됩니다 |
| `no_answer` | 24 | 위 지식으로는 답할 수 없는 질문. 모두 그럴듯한 틀린 답이 있는 것으로 고릅니다. 세 종류를 8개씩: (가) 위에 있는 대상에 대해, 그 대상에는 사실이 없는 다른 것을 묻기 (나) 지식에 없는 구분을 넣어 묻기(야간, 작년, 외국인, 폐업한 경우 등) (다) 지식에 없는 대상에 대해 묻기. **20개 이상은 속성 낱말을 쓰지 않은 자연스러운 말투로** |

각 문항 형식:

- `expect`: 지식에 적힌 값과 글자 하나까지 같은 값. `no_answer`는 null.
- `needs`: 근거 지식 번호 목록. `no_answer`는 [].
- `check` 문항만: `expect`는 **참인 값**(질문에 댄 값이 아니라 지식의 값)이고, `claim`은 질문에 댄 값이 참인 값과 같은 뜻이면 true, 다르면 false.

## 출력

아래 모양의 JSON 하나만 돌려줍니다(UTF-8, 설명 문장 없이).

```
{"questions": [{"id": "Q01", "kind": "direct", "text": "...", "expect": "10%", "needs": ["F01"]},
 {"id": "Q53", "kind": "check", "text": "...", "expect": "126", "claim": true, "needs": ["F10"]},
 {"id": "Q57", "kind": "no_answer", "text": "...", "expect": null, "needs": []}]}
```
