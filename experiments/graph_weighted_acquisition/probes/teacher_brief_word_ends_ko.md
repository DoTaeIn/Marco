# 줄기와 말끝 수업 안내문 (외부 교사용)

`---` 아래를 그대로 교사에게 준다. 교사는 이 저장소의 코드, 수업, 시험 문항을 보지 않는다. 낱말은 기초 낱말 942개 가운데 `다`로 끝나는 290개 전부다. 실패한 질문에서 고른 것이 아니다. 왜 필요한지는 `CONTRACT.md`의 "Basic words" 절에 있다: 언어 팩이 아는 어미가 9개, 이음말이 6개뿐이라 활용한 낱말이 수업에 닿지 않는다.

---

당신은 한국어 교사입니다. 낱말이 문장 안에서 모양을 바꿔 나올 때 그것이 어느 낱말인지 알아보는 데 쓸 자료 두 가지를 적습니다. 뜻은 적지 않습니다. 모양만 적습니다.

## 1. 줄기

아래 낱말 290개마다 한 줄을 적습니다. 줄의 모양은 `낱말<탭>바탕줄기<탭>으줄기<탭>어줄기`입니다.

- **바탕줄기**: `-고`, `-지`, `-는`이 붙기 직전까지의 꼴. `걷다` → `걷`, `알다` → `알`.
- **으줄기**: `-면`, `-니까`, `-려고`가 붙기 직전까지의 꼴. `걷다` → `걸으`, `먹다` → `먹으`, `가다` → `가`, `돕다` → `도우`.
- **어줄기**: `-서`, `-요`, `-도`가 붙기 직전까지의 꼴. `걷다` → `걸어`, `먹다` → `먹어`, `가다` → `가`, `오다` → `와`, `쓰다` → `써`, `하다` → `해`.
- 한 칸에 꼴이 둘 이상이면 `/`로 가릅니다. 받침이 빠지는 꼴도 여기에 적습니다(`알다`의 바탕줄기 → `알/아`, `하다`의 어줄기 → `해/하여`).
- 활용하지 않는 낱말(이름씨, 어찌씨)은 세 칸을 모두 `-`로 둡니다.
- 낱말을 빼거나 더하지 않습니다. 아래 순서 그대로 290줄입니다.

## 2. 말끝

일상에서 흔히 쓰는 것만, 목록마다 한 줄에 하나씩 적습니다. 드문 것, 옛말, 글에서만 쓰는 것은 적지 않습니다.

- **바탕줄기 뒤에 붙는 말끝** (`고`, `지`, `는`, `나요` 같은 것). 80개 안쪽.
- **으줄기 뒤에 붙는 말끝** (`면`, `니까`, `려고` 같은 것). 80개 안쪽.
- **어줄기 뒤에 붙는 말끝** (`서`, `요`, `도` 같은 것). 80개 안쪽.
- **이름씨 뒤에 붙는 말** (`을`, `를`, `에서` 같은 조사). 겹쳐 쓴 꼴(`에서는`, `까지도`)도 흔하면 적습니다. 80개 안쪽.

지킬 것:
- 줄기의 마지막 글자에 받침으로 들어가는 말끝은 그 낱자로 시작하게 적습니다(`ㄴ`, `ㄹ`, `ㅂ니다`, `ㅆ어요`).
- 말끝이 이어 붙은 꼴도 흔하면 한 줄로 적습니다(`ㅆ는데`, `려면`, `ㄹ 수 있나요`는 띄어 쓴 그대로).
- 높임, 물음, 시킴, 이음, 꾸밈 꼴을 고루 넣습니다.

## 출력

설명 문장 없이 아래 다섯 덩어리만 돌려줍니다.

```
# 줄기
걷다	걷	걸으	걸어
알다	알/아	알/아	알아
바다	-	-	-
...

# 바탕줄기 뒤
고
...

# 으줄기 뒤
면
...

# 어줄기 뒤
서
...

# 이름씨 뒤
을
...
```

내기 전에 확인합니다: 줄기 290줄, 순서 그대로, 칸은 탭으로 가름, 빈 칸 없음.
