# Example-supervised graph acquisition pilot

This isolated experiment learns a small character-span-to-graph grammar from teacher-supplied texts, semantic graphs and source spans. It is supervised learning, not unsupervised discovery. The same parser processes passages and questions; no language-specific seeds or tokenizers are provided. The accepted reader, native search and older evaluations are not modified.

The v2 input format and a complete ASCII example are in [SCHEMA.md](SCHEMA.md). Each dataset contains `examples`; the development dataset also contains separate passage/question `pairs` with expected decoded bindings. Use disjoint training and development examples. The expected bindings enter validation only, never candidate generation:

```sh
PYTHONPATH=. python -m experiments.graph_example_acquisition.driver \
  --train TRAIN.json --dev DEV.json --contrasts CONTRASTS.json --output REPORT.json
```

The report contains the induced rule and patch inventory, source example IDs, bounded costs, accepted and rejected candidate bundles, graph derivations, native validation and final admission reasons. `v2.induce` enumerates training-only candidates; `v2.acquire_incremental` runs the guarded greedy loop; `v2.parse` returns graph candidates and completion status; and `native.run_pair` executes predicted graphs with the existing query-graph engine. `--max-proposals` and `--max-rounds` set finite acquisition bounds; parser completeness for the accepted grammar and candidate-search completeness are reported separately. The older `acquire.py` is a fail-closed v1 scaffold, not the v2 admission path.

Templates are derived from authored graph spans. Only an explicitly copied `value` anchor becomes an open hole after at least two distinct fillers were observed; other anchors stay within their finite observed forms. The learner also proposes a patch when examples differ in one text gap and either one semantic-literal value or one added/deleted edge with authored evidence. It searches bounded, cost-ordered ordinary bundles of at most two productions, and union dependency closures containing their missing child rules plus at most one additional rule. Each accepted bundle must add a training derivation and a newly passing development pair, retain earlier successful development behavior, and introduce no graph mismatch or ambiguity. Final admission checks every training and development graph, four distinct category-labeled pairs, independent mechanically checked contrast records and formal query ablations, source spans, and native execution of the predicted passage and question graphs. Development data selects candidates; use a separate untouched test set to measure generalization. Category labels require independent teacher review.

The graph carrier uses `direct_text` as metadata for the annotated utterance. Source, negation and scope are checked through explicit graph edges; this does not establish whether an event actually occurred or whether a natural-language interpretation is correct. Output is graph tuples and source evidence, not generated prose.

The experiment is intentionally narrow: patches update one literal edge or insert/delete one edge alongside one text gap; nested recursion, overlapping anchors or unsupported variable-length interior offsets, more than eight nodes, empty-answer native checks and complex query frontiers are unsupported or held. Missing evidence, incomplete search, ambiguous parses, unknown relevant role bindings and projected candidates without one unambiguous copied value also hold. Candidate and search bounds mean any minimum is conditional on the explored space, not a globally optimal grammar. See [CONTRACT.md](CONTRACT.md) for details.

A bounded two-child production can also be induced when at least two training parents are exactly the span-shifted, ID-renamed disjoint unions of independently derivable child graphs with the same observed separator. Its child rules can be reused in new combinations. It does not invent shared-entity identity or merge nodes; parents requiring such links remain unsupported. When a copied-value candidate contains a complete incompatible typed child graph with relational evidence, that candidate is rejected with the child derivation recorded. A short observed operator substring alone does not invalidate a compound name.
