# 법리 그래프

사건마다 다시 쓰지 않는, 공유되는 법 구조. **여기는 사건이 없다** — 법만 있다.
조문 원문은 `../../지식/법지식/` 에 있다.

```
게임/legal/
  법리_*.kg           요건 구조. 조문 하나 또는 죄명 하나당 파일 하나
  개념망_한국어.kg     단어 관계 (과도 -상위-> 흉기). 죄명과 무관하게 공유
```

## 파일 나누는 기준

| 무엇 | 어디 |
|---|---|
| 조문 원문 | `../../지식/법지식/` — 손대지 않고 보관 |
| 요건과 그 관계 | `법리_<죄명>.kg` — 죄명마다 한 파일 |
| 단어 사이 관계 | `개념망_한국어.kg` — 전부 공유, 죄명 무관 |
| 이 사건의 증거·사실 | **여기 아님.** `../cases/사건_*.md` |

**법리 파일을 죄명마다 나누는 이유:** 서브셋 필터가 `목표`의 연결 덩어리만 로드한다.
정당방위 사건에 절도 요건이 섞이면 매처가 오염된다. 파일을 나눠두면
사건이 필요한 것만 `포함` 한다.

## 새 죄명 추가하기

```bash
# 1. 원문을 받아 둔다
#    법지식/형법_절도.txt

# 2. 조문에서 모르는 개념을 뽑는다
python engine.py --mine legal/법리_형법21조.kg ../지식/법지식/형법_절도.txt

# 3. 법리_절도.kg 을 만들고 요건을 적는다 (출처 @ 표기 필수)
# 4. 확인
python engine.py --diagnose legal/법리_절도.kg   # 증거가 0이면 라이브러리로 정상
python engine.py --tune legal/법리_절도.kg   # 노드끼리 겹치는지
```

## 출처를 반드시 적는다

```
정당방위 @형법 21조 1항: "정당방위입니다" | ...
회피가능성 @판례(퇴각의무 불요): "도망칠 수 있었습니다" | ...
```

근거 없이 만든 노드는 이 시스템의 유일한 보장을 깬다.
`--diagnose` 가 출처 없는 개념을 세어 보여준다.

## 아직 없는 것

- 절도·사기·명예훼손 등 다른 죄명 (실험/graph.kg 에 예시만 있음)
- **판례** — 사실→요건 링크의 진짜 출처. 조문은 요건 *이름*만 준다
- 개념망이 흉기 14줄뿐. KorLex·위키데이터에서 채울 자리
